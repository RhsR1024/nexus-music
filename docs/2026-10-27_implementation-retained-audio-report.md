# 2026-10-27 批次5E：保留音频副本管理

本地音频从列表移除、移出扫描范围后，已有设备副本仍可被播放器解析，但缺少管理入口。本批新增正式“管理保留副本”入口，列出原因和记录容量，支持单首/全部恢复，以及明确确认后删除单首设备副本。它是音枢自己的数据管理能力，不新增Sollin结论、采集或第三方代码。

## 行为

恢复只修改本地索引，不触发播放、不改权威队列。扫描范围外副本恢复为独立手动导入项，清除过时扫描位置，不扩大目录授权；零扫描目录重扫仍应保留。隐藏项保留既有身份、收藏及其他元信息。

删除复用原生在用租约和暂存日志/数据库提交/清理协议。原文件不删除，歌单、历史、权威队列引用保留；提示重新导入相同文件可恢复引用。确认后在串行队列内再校验仍是保留项，避免迟到确认删除刚恢复的可见音频。数据库失败恢复暂存文件，最终清理失败明确提示下次启动处理。

正式列表虚拟化、统一间距/圆角/字体令牌、44pt命中区、安全区、可读长标题、忙碌防重入和错误活跃提示。容量来自索引记录，不冒充实时磁盘扫描。
