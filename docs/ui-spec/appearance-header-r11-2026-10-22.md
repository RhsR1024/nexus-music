## 图标家族证据更正

r10 回执把参考图标描述为“SF Symbols 家族”。本轮对 `resource/reference-ui/sollin-2026-10-18` 的图标裁片与 Sollin IPA 的字体子集做了交叉核对，结论应更正为 **CupertinoIcons**：

- Sollin 为 Flutter；`FontManifest.json` 只声明 `MaterialIcons` 与 `packages/cupertino_icons/CupertinoIcons` 两个字族。
- Material 子集（61 个 BMP 码位）不含 circle/layers/photo；Cupertino 子集包含 `f400`、`f8e7`、`f768`。
- 用 CoreText 以 400pt 渲染：`f400` = 实心圆，`f8e7` = `layers_alt_fill`（顶部菱形+两条折带），`f768` = `photo_fill`（圆角矩形+白圆/山形）。三者与参考裁片的形状、宽高比（1.00 / 1.03 / 1.28）逐项吻合；参考裁片墨迹宽高比为 1.00 / 1.08 / 1.26。
- 当前产品仍是 MCI `circle`、Ionicons `layers`、FontAwesome5 `image`，因此 4855 的 3 项 major 保留；替换目标应为 CupertinoIcons 上述三个码位，而不是新增 SF Symbols 原生依赖。
