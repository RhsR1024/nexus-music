# 4854 经典播放态锚点清单 v1（冻结 2026-10-22）

本清单是[页面相似度量表](page-similarity-rubric-2026-10-22.md) D1/D2 在 4854 上的冻结锚点与关键区声明。冻结后不再因结果回调；后续修改按新清单升版，并在回执中给出新旧差异。

## 测量口径

- 参考与候选均为 1290×2796、430×932pt（3x）。参考 `resource/reference-ui/sollin-2026-10-18/IMG_4854.PNG` 经 `sips -m sRGB` 转 8bit 后量测；候选为同源码 Release 采集的 8bit sRGB PNG。
- 墨迹阈值：工具图标/上一首/下一首 RGB 三通道均 <160；播放圆钮 <170；进度条已播放段 <200；进度条全长（含未播放尾段）<240；暂停条为圆钮内三通道均 >200 的亮墨。坐标 3x→pt，末位约 0.33pt 为像素量化。
- 进度拇指：在 [340,655,400,685]pt 内按列统计暗像素，列高 ≥20px（6.67pt，进度线仅 5pt）的列定义为拇指，取列区间中心。播放进度端点即拇指中心。
- 脚本：`build/ui-method-r17-20261022/measure-4854.mjs`；参考值冻结于 `build/ui-method-r17-20261022/reference-anchors.json`。全部数值可用脚本与冻结 PNG 重算。
- D1 只用**布局锚点**（位置/中心/轨道端点/行 y）。图标墨迹宽高与内部笔画归 D3 记账，沿用 4855 A5/A6 做法（D1 以中心/左缘判定，字形尺寸与宽度缺陷记 D3），避免同一字形缺陷在 D1/D3 重复扣分。
- 状态：iPhone 常态、`blush + rose`、light、`solid`、播放中 93.6%（夹具 seek 1:52/2:00，截屏后恢复暂停）、fontScale 1、zh；参考 04:26/04:44=93.66%。
- 参考与候选的封面、标题、歌手、歌词、时间数字、音质脚注为内容差异（D5=75）。时间行只比较**外缘与墨迹上缘**（布局锚点），不比较文字宽度（字符串不同）；脚注只比较中心（居中布局），不比较宽度。候选左上“收起播放页”箭头是音枢可达性扩展，参考无此控件，冻结为**声明性产品扩展**，不计入 D1/D3；其位置在 `ignoreTop` 邻域，回执中披露其可见范围。

## C. 冻结关键区（D2）

关键区沿用 `docs/ui-spec/4854-classic.json` 中**实施前已存在**的三个控件区，矩形与遮罩均不改动；本轮只把它们同时声明为 `criticalRegions`：

| 标签 | 矩形（px） | 覆盖（pt） |
|---|---|---|
| progress | [70, 1975, 1150, 75] | 23.33..406.67 × 658.33..683.33 |
| transport | [330, 2170, 630, 265] | 110.00..320.00 × 723.33..811.67 |
| tools | [150, 2475, 990, 100] | 50.00..380.00 × 825.00..858.33 |

- 主操作区为 `transport`；任一关键区失败即触发 G4，且 D2 不能记满分。
- 关键区颜色/材质报告沿用规格内已声明的 `controlColorRegions`（两条暂停条）与 `colorPatches`（play fill、pause bar），不新增、不移动。
- 关键区之外的封面、歌词、标题、时间与脚注仍由 `contentMasks` 排除在控件门禁之外；D2 不因内容不同扣分，D5 单独记账。

## 使用与披露

- 本清单冻结的是锚点元素、参考值、量测方法与关键区，不冻结候选结果。候选列在本轮采集完成后回填，偏差按最差项计。
- 候选结果若暴露新的控件级差异，按 D3 记缺陷；若暴露新的布局级差异，先按本清单量测，只有缺失/错层/遮挡/裁切或 >5pt 才触发 D1=0。
- 未覆盖锚点：封面裁切、歌词行数与字号。时间/脚注为内容文本（不同字符串），本轮只做 A14–A17 布局结论，不做字形级 D3 结论；歌词行数与封面裁切在 D5 记 75。
