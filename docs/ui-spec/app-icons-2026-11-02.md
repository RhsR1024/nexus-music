  通道名或偏好键。

## 场景

| 场景 | 预期 |
| --- | --- |
| 支持替换 | 读取系统当前图标；“珊瑚”对应主图标，五个 `NexusAlt*` 名称对应有限白名单 |
| 不支持替换 | 显示明确系统能力说明，所有选择禁用；不伪造成功状态 |
| 切换成功 | 系统确认后重新读取并展示实际返回状态，不改播放、队列或外观配置 |
| 用户取消或系统失败 | 保留原选择并显示“切换图标失败：…”；不乐观更新 |
| 重启 | 重新从系统读取当前图标；不依赖 JS 保存值 |
| 恢复主图标 | 以 `nil` 调用系统 API，成功后珊瑚项成为当前项 |
| 并发选择 | 切换期间禁用全部选项，原生模块拒绝重复请求 |
| SpringBoard | 改变后桌面图标与标签可见，并可从改变后的图标打开应用 |
| 大字/VoiceOver | 三列网格可换行且每项至少 44pt；单选角色、选中/忙碌/禁用状态和状态摘要可朗读 |

## 视觉与布局契约

- 外观总览增加真实的“软件图标”行；子页继续使用现有 `SheetModal` 和标题。
- 子页顶部先显示当前系统状态，再显示说明与六项网格；网格使用三列、
  12pt 列间距与 14pt 行间距。每项整体接近静态证据的 `0.82` 宽高比，
  图像本身保持正方形。
- 选中态使用当前主题强调色描边和勾选；图标图像使用系统式圆角预览。
  颜色来自六份不透明 RGB PNG，不使用参考素材或远端图片。
- 错误文本紧邻选择器，使用既有主题强调色与 `alert` 语义。
