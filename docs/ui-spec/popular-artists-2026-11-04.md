# 网易热门歌手目录场景

范围为发现→网易→热门歌手→艺术家歌曲/专辑→返回目录。沿决策0079按功能与UI质量验收，没有同态Sollin截图，不运行像素相似度评分或声明动效等价。iPhone常态、默认blush/rose；公开目录可随平台更新，逐次计数不作为总数。

实现沿用正式发现页：24pt水平内容边距、现有响应式网格及封面、44pt以上按钮；不新增截图专用页面。目录摘要标为“热门目录摘要”，与搜索摘要、详情资料及“热门歌曲不代表完整曲库”分开。目录与详情均使用既有正式组件。

| 状态 | 验收条件 |
| --- | --- |
| 初始/加载 | 正常发现入口可达；网易平台下显示热门歌手；加载有可取消操作 |
| 首屏 | 30位公开歌手，封面/名称/进入歌曲与专辑说明无裁切或遮挡 |
| 续页 | 追加第二页达到60位；跨页重复身份拒绝，保留旧内容及原失败页重试 |
| 歌手歌曲 | 正式详情可达，热门目录摘要和公开热门歌曲范围明确 |
| 歌手专辑 | 使用既有artist albums读取；不把歌手ID当成歌单ID |
| 返回/刷新 | 返回保留60位；刷新成功从第一页替换，失败保留已加载内容 |
| 取消/错误/空态 | 沿发现页代次/AbortSignal；旧请求不能覆盖新页面；终页空态不制造更多页 |
| 播放隔离 | 浏览不请求音频或改队列；明确点歌曲才沿现有playTracks处理 |

真实Release专项在独立PopularArtistsTests中登记；默认综合测试跳过此匿名真实服务专项。源码、精确xcresult、截图与人工观察结果补记于[批次回执](../2026-11-04-popular-artists-report.md)。当前未完成截图验收，不据此计UI完成量。
