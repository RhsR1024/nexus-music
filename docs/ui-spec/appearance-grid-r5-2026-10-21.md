- 主题芯片改为三列单元容器，单元宽约 31.4%，列距 7.6pt、行距 8.5pt；主区 11 项自然形成 3/3/3/2。音枢额外 `柔和`、`经典` 仍留在 `视觉参数` 之后的真实可滚区域。
- 首个操作改为真实书签收藏：短按收藏/取消收藏当前主题并持久化，长按保留原有随机切换能力；图标、44pt 命中区和无障碍状态分别验证。
- 滑轨减号改为 12×1.5pt 原生横线，加号使用横竖原生线组成，不再依赖字体字符；按钮尺寸与滑轨容器不变，避免跨父子层补偿。
- 本轮不改容器顶缘、Sheet 渐变、颜色字段边界、卡片透明度、滑轨轨道/刻度/thumb 或关键区定义。目标仍是各关键区三轴通过；4855 主题区、标题/操作和 4856 视觉参数区为本轮直接观察项。

快速入口继续使用正式组件与生产导航；修改前后均绑定精确构建、fixture、截图与工具哈希。正常入口的收藏持久化、关闭/重开、真实主题可达和滑块步进另验。
