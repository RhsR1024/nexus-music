# 网易云平台歌单加歌 UI 场景

日期：2026-11-18。场景：网易云在线歌曲 → 歌曲操作 Sheet → 添加到网易云歌单 → 选择当前账号创建的歌单。该页面是音枢功能 UI，不是 Sollin 参考页面的像素对齐项；按 0079 以层级、可达、反馈、无裁切和正常操作验收，不设像素相似度门槛。

## 环境与几何

| 项 | 值 |
| --- | --- |
| 主参考环境 | 1290×2796 截图、430×932pt、3x；iPhone 15 Pro Max 模拟器 iOS 26.3.1 |
| 外层 | 正式 `SheetModal` + `ScrollView`，背景 `palette.background[0]` |
| 内容容器 | `space.lg`（16pt）四边内边距、`space.md`（12pt）纵向间距、`space.xl`（20pt）底部留白 |
| 标题区 | 横向布局，标题 `typography.title`（22pt/28pt）；说明 `typography.caption`（13pt/19pt） |
| 返回按钮 | 最小高度 `controls.hit`（44pt），水平 `space.md`，`radius.md`（12pt） |
| 歌单行 | 最小高度 `controls.hit + space.md`（56pt），水平 `space.md`，垂直 `space.sm`，`radius.md`，hairline 边框 |
| 行文字 | 歌单名 `typography.body`（15pt/22pt）；“N 首 · 创建的歌单”为 caption；右侧“添加”为 accent 色 caption |
| 状态文字 | `accessibilityLiveRegion=polite`，加载/错误/空态均位于滚动内容内 |
| 父入口 | 歌曲操作动作行最小高度 56pt；“添加到网易云歌单”与平台收藏、本地歌单入口分开 |

## 验收状态

| 状态 | 期望 |
| --- | --- |
| 入口可见 | 在线网易云歌曲且恰好一个网易云账号时显示；多账号不显示并提示先收敛 |
| 加载 | 显示活动指示和“正在读取或更新网易云歌单…”；返回按钮暂时禁用 |
| 列表 | 只显示当前账号 `kind=created` 的歌单；标题、曲目数、添加动作完整可读 |
| 空态 | “当前账号还没有可添加的网易云歌单”，不伪造目标 |
| 读取失败 | 明确错误和“重新读取歌单”，不保留旧列表作为可操作目标 |
| 回读确认 | 成功返回父 Sheet，显示“已添加到「…」”；`code:200` 不单独作为成功 |
| 幂等 | 已存在时显示“这首歌已在「…」中”，不增加写入 |
| 写入拒绝 | 显示“网易云音乐拒绝添加到歌单，请检查账号权限”，列表仍可重试 |
| 未确认/未知 | 提示可能已提交但未确认，要求重新读取核对，不自动重发写入 |
| 登录/账号变化 | 分别提示重新登录或重新打开歌曲操作，不显示成功 |
| 取消 | 退出子视图或切歌后迟到响应不能发布成功 |

## 本批截图

最终 Release `SourceUITests-1794983029561` 的 6 张 1290×2796 截图位于 `build/ui-netease-playlist-tracks-screens-20261118-r7/`：

- `006`：父歌曲操作 Sheet 的独立平台加歌入口。
- `005`：当前账号创建的 Synthetic Target Playlist，2 首。
- `004`：回读确认后父 Sheet 的“已添加”状态。
- `003`：重复添加后的幂等状态。
- `002`：写入拒绝的错误状态。
- `001`：恢复后重试成功状态。

`001` 与 `004` 的 SHA-256 相同；两者是同一滚动位置和成功状态下的两个断言附件，文档明确记录，不把它当作两个不同视觉状态。
