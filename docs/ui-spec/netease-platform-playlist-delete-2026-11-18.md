# 网易云平台歌单删除 UI 场景

日期：2026-11-18。场景：设置 → 账号 → 网易云账号歌单 → 读取账号歌单 → 删除当前账号创建的网易云歌单。该页面是音枢功能 UI，不是 Sollin 参考页面的像素对齐项；按决策 0079 以层级、可达、反馈、无裁切和正常操作验收。

## 环境与几何

| 项 | 值 |
| --- | --- |
| 主参考环境 | 1290×2796 截图、430×932pt、3x；iPhone 15 Pro Max 模拟器 iOS 26.3.1 |
| 外层 | 设置页正式 `ScrollView`；账号歌单卡片 `radius.xl`（20pt）、hairline 边框、`space.lg`（16pt）内边距、`space.md`（12pt）纵向间距 |
| 歌单行 | 横向布局，最小高度 `controls.hit + space.xl`（64pt），`space.md`（12pt）垂直内边距、行内 `space.md` 间距、顶部 hairline 分隔 |
| 行主区 | `flex:1`；歌单名 `typography.body`（15pt/22pt），类型/曲目数/预览说明为 `typography.caption`（13pt/19pt） |
| 删除按钮 | 最小 `44×44pt`，水平 `space.md`（12pt），`radius.md`（12pt），hairline 边框，文字为 accent 色 caption |
| 状态文字 | `accessibilityLiveRegion=polite`，位于列表下方、滚动内容内 |
| 确认弹窗 | 系统 `Alert`，标题“删除这个网易云歌单？”，取消为 cancel，删除为 destructive |
| 重命名说明 | 位于新建区末尾，caption 色；明确“暂未开放”，不提供假入口 |

删除按钮只出现在 `kind=created` 的歌单行；收藏歌单仍可预览导入，但不显示删除控件。成功后只从当前目录移除该行，不删除音枢本地歌单或歌曲。

## 验收状态

| 状态 | 期望 |
| --- | --- |
| 列表 | 当前账号创建和收藏歌单完整可读；创建行有独立“删除”按钮，收藏行没有 |
| 重命名边界 | 显示“重命名暂未开放：现有协议需要同时写入描述和标签，音枢不会用猜测值覆盖平台资料。” |
| 平台说明 | 网易云卡片提示新建/删除会直接修改平台数据；QQ/酷狗卡片仍声明导入不会修改平台歌单 |
| 确认 | 点击删除先弹出系统确认，说明将删除平台歌单、不会复制到音枢；默认不写入 |
| 取消确认 | 关闭弹窗后行保留，删除写入为 0 |
| 提交中 | 显示“正在删除网易云歌单”和取消操作，避免重复点击 |
| 回读确认 | 只有 `user/playlist` 再读确认目标缺席后才显示“已从网易云音乐删除「…」并回读确认” |
| 已缺席 | 目标本来不在目录时显示“「…」已不在账号歌单中”，零写入 |
| 写入拒绝 | 显示“网易云音乐拒绝删除歌单，请检查账号权限”，行保留并可重试 |
| 未确认 | 显示“删除请求可能已提交，但未回读确认；请重新读取账号歌单核对，不要重复删除”，行保留 |
| 登录/账号变化 | 分别提示重新登录或重新读取歌单，不显示删除成功 |
| 取消操作 | 写前取消显示“操作已取消”；写后取消显示未确认，不冒充成功 |

## 验收方法

- 合成网易云账号 `netease:9000000000000000007`，正式 `MusicAccounts`、`AccountPlaylists`、`NeteasePlaylistDeleteClient` 和主题，仅 HTTP 传输进入本机夹具。
- 夹具初始返回一个创建歌单 `Synthetic Delete Playlist` 与一个收藏歌单 `Synthetic Favorite Playlist`；控制接口记录 `user/playlist` 读取、`playlist/remove` 写入、无效请求和剩余目标。
- XCTest 覆盖：列表与删除可见性、重命名说明、确认取消零写入、拒绝后行保留与重试、成功回读后行移除、未确认时行保留。
- 截图统一为 1290×2796；逐张亲看，检查标题、行文字、删除按钮、确认弹窗和状态文字无裁切、无重叠。
