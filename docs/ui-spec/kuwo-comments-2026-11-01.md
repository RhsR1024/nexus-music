# 酷我公开评论功能验收场景

本轮复用既有评论 Sheet，不修改几何、图标或动效；仅补公开来源与状态路径。iPhone 常态验收，不增加像素对齐完成量。UI 按决策0079核对可读性、分区、反馈和操作可达性。

合成协议：正常搜索选择酷我，歌曲菜单打开正式评论 Sheet；首屏热门/最新、总数、长文本与子回复归属可见；加载更多首次失败保留旧内容，重试仍请求相同 start 并追加下一页；总数更新；刷新失败保留后，明确空响应可替换为零条空态；关闭不触发播放。合成场景仅作功能压力验证，不作默认主题颜色评分。

真实服务：生产入口搜索公开歌曲，酷我原曲身份读取匿名 HTTPS 评论，热门/最新分区、实际滚动可见的最新标题、正总数及第二页新增数量分别断言；关闭后无播放副作用。保留当次真实数量而不写死服务总数，不记录真实昵称/正文到仓库。检查默认主题下固定头部、长文本、回复、分页及边界无可见遮挡；表情字形另记实际情况。

每轮使用新输出目录与精确 xcresult。manifest 绑定源码/原生/JS 包，导出截图后逐张验证哈希并亲看。首屏来源为两个独立读取，热门失败不得悄悄冒充空热门。播放换源不改变评论原曲身份；不验证点赞/发评写入或账号专属评论。
