# 设备音量与 App 音量分离

本批对应 F29/J26 中可独立实现的音量控制增量。“播放与歌词 → 播放控制”继续保留音枢自己的 App 相对音量，并在其后增加系统输出音量卡片。两者共用现有原生音频会话和单一权威队列，不建立第二播放器，也不把系统音量镜像写入偏好。

固定场景为 430×932pt / 1290×2796px @3x 的 iPhone 15 Pro Max 模拟器、iOS 26.3.1、Release、生产入口、默认 blush + rose 主题和正常设置导航。检查以下状态：

1. App 音量可见、可拖动，数值显示 0–100%；拖动只修改音枢播放器的相对音量。
2. 系统输出音量卡片显示“设备音量”和“系统输出”，包含至少 44pt 的可调无障碍区域。
3. 真机分支由 Apple `MPVolumeView` 显示系统滑块；当前输出设备的音量值、耳机、蓝牙和 AirPlay 路由都由 iOS 管理。
4. 模拟器不提供系统音量滑块，也不暴露伪 0% 值；卡片显示“当前环境未提供系统音量滑块”，无障碍值为同一明确说明。
5. 原有“系统音频输出”路由入口保持可见；App 音量修改、Home 恢复和进程终止重启后，暂停意图、时间和队列不改变。

颜色、字体、间距和卡片圆角沿用播放设置的现有 token。系统滑块自身的轨道、拇指、设备列表与路由图标由 iOS 决定；截图不用于评价系统控件的外观一致性。

模拟器可以验证正式组件、布局、可访问性、App 音量持久化和系统控件的不可用降级。实体扬声器、耳机、蓝牙或 AirPlay 的系统音量变化、VoiceOver 实际增减手势、路由断开、音频会话中断、签名安装与 iOS 27 行为必须在大屏 iPhone 真机上另行验收。
