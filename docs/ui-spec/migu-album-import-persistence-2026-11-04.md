# 咪咕公开数字专辑本机副本持久化

沿既有公开目录范围，不新增Sollin结论或平台账号能力。正式入口：搜索→专辑→咪咕→No.6 Collaborations Project→公开曲目导入→音乐库→重启→本轮副本清理。

验证先确认没有同名原有副本；如已有则跳过并保留。读取7首公开曲目的实际标题次序，不制造发行版缺失曲目。取消预览后应无副本；明确确认后本机歌单应有7条、原咪咕来源与相同顺序，描述保留“来自平台公开目录，仅包含本次可读取的曲目。”；重启后逐项复核，再通过正式删除确认移除本轮副本并重启核对。

使用iPhone常态、默认主题、正式组件与现有44pt触控标准。截图包含公开范围预览、创建/重启后的描述和歌曲、清理状态；不评分像素相似度或声明动效等价。只验证元数据导入/持久化，不点歌曲或声明真实音频播放。

测试类为独立`MiguAlbumImportTests`，默认CI不执行匿名真实服务专项。沿现有公开目录测试的独立服务端口与运行期间实际安装包快照，绑定精确xcresult、来源摘要和新截图目录。
