# QQ 公开评论回复展开

本批复用 IPA 离线 `E-033 → F-032 → P-032` 的既有评论 Sheet，不新增 Sollin 采集或像素/动效完成声明。QQ 公开协议、真实服务和分页事实独立记录。

- 正常入口：搜索→选择 QQ 音乐歌曲→歌曲更多→歌曲评论；不启动播放，不读取账号。
- 前置状态：根评论必须有当前原曲绑定和服务返回的正向 `ReplyCnt`；其他歌曲或外部拼接根 ID 不显示可展开入口。
- 展开目标：作者头像/可选地区、正文、日期/点赞、目标引用；失败保留已显示回复，重试沿用同一 `RankScore + SeqNo` 游标。
- 分页：每页 20 条，正式入口按可见“加载更多回复”继续；重复页、空追加和 500 条显示上限停止。
- 空态：成功但零行显示“本次未取得可展示的回复。”，不显示为空白线程。
- 收起：取消在途回复读取并从界面移除已展开正文；迟到结果不能重新打开。
- 刷新/换歌/关闭：沿用共享评论会话的取消和迟到隔离；刷新失败保留旧评论，评论分页不替代回复分页。
- 几何沿用现有 Sheet：36pt 根头像、28pt 回复头像、14pt 左侧层级线、至少 44pt 展开/重试/加载按钮；内容保持最小宽度和换行，不遮挡固定标题或安全区。
- 默认主题 `blush + rose`、iPhone 常态；本轮不声明参考像素相似度、横屏全矩阵、动态字号/VoiceOver 或连续动画一致。

合成场景：

1. 41 条回复的根→首屏两行→身份/地区/引用。
2. 第二页失败→首屏保留→同 `8/202` 游标重试→第三行追加。
3. 收起回复→正文消失。
4. 成功空回复→明确空态。
5. 根评论第二页失败/同游标重试/总数更新。
6. 刷新失败保留旧行→真实空评论 0 条。

真实场景：

1. 正式 QQ 公开歌曲搜索和评论入口。
2. 滚动到可见正数回复控制→展开→至少一条真实回复行。
3. 查看真实引用/作者身份→加载第二页根评论。
4. 关闭 Sheet，全程不启动播放。
