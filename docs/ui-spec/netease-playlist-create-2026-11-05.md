## 验收状态

- 空名称：按钮 disabled，不发起请求。
- 私密默认：创建请求使用 `privacy:"10"`；用户显式切换后才发送 `"0"`。
- 创建成功：显示“已创建网易云歌单「合成网易云歌单」并回读确认”。原2026-11-05场景夹具 `writes=1`、`reads=1`、`invalid=0`；该场景未覆盖创建后的导入预览。
- 创建后名称清空，按钮回到禁用；账号卡仍保留“读取账号歌单”显式刷新入口。
- 失败/未确认：状态文字说明可能已提交时不要重复创建；不自动重试。

## 2026-11-10 目录生命周期补验

创建确认后不直接插入未登记的目录条目，清空旧目录并显示读取入口；显式重读后可以预览新建空歌单。开始普通刷新时旧行立即消失；失败显示重试提示，取消后的迟到结果不得恢复旧行，成功重试后可再次预览。Release `SourceUITests-1794296288625` 覆盖全部路径，最终 `writes=1/reads=7/invalid=0/held=0`；4张截图来源核验通过，默认主题下状态与操作可达。详见[修正回执](../2026-11-10-account-playlist-refresh-report.md)。
