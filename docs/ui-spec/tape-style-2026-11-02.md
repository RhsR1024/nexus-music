# 磁带封面样式 UI 场景（2026-11-02）

## 来源与边界

- 需求来源：`U`（用户补充的“粉粉主题磁带皮肤”），不是从 Sollin IPA 直接恢复的视觉常量。
- 既有 Sollin 证据只支持“封面圆角可调”和播放器皮肤分区；磁带隐喻由音枢原创实现。
- 本批不新增二进制采集、私有服务探测或截图专用页面。可复用既有外观证据链，不把用户补充写成语义已由 IPA 观测。

## 场景

| 场景 | 预期 |
| --- | --- |
| 关闭 | 保持当前封面与圆角，不出现磁带外壳；作为默认状态 |
| 开启、封面可用 | 主要播放封面外层显示粉调磁带壳、底部双卷轴和四角定位点；实际匹配录音封面仍完整承担歌曲身份 |
| 开启、封面不可用 | 磁带壳保留，内部沿用现有首字/音符回退，不请求替代图片 |
| 浅色/深色主题 | 外壳取当前强调色，卷轴与标签带保持对比；底色切换不改变歌曲或队列身份 |
| 经典、封面沉浸、声波核、AM、AM2 | 主封面使用同一磁带组件；迷你封面、列表缩略图和其他非播放器封面保持原样 |
| 写真、黑胶、歌词舞台 | 保留各自主导视觉；不把小尺寸标签或背景强行替换成磁带，避免伪装成另一播放模式 |
| 小尺寸封面 | 小于 112 pt 的回退区域使用普通封面，避免卷轴细节不可读 |
| 减少动态效果 | 磁带为静态装饰，没有新增动画、闪烁或传感器输入 |
| 大字/VoiceOver | 开关为原生可访问 Switch，标签说明应用范围；磁带壳不重复朗读歌曲信息，标题/歌手仍由既有可访问文本提供 |

## 视觉与布局契约

- 外层占位与现有主封面正方形视口一致，避免切歌、歌词和控制区跳动。
- 外壳圆角跟随 `coverRadius`，并对绘画像素做边界收紧；封面内部圆角略小于外壳。
- 粉调外壳使用当前主题强调色；底部卷轴带使用固定的高对比深色层，卷轴内孔透出强调色。
- 四角定位点、卷轴和侧边条均由 React Native `View` 绘制，不增加位图资源或第三方图标混搭。
- 外壳只覆盖播放页主要封面。现有 `Cover` 的加载、取消、失败和缓存行为继续复用。

## 验收

1. 关闭状态不改变现有播放器截图和控制布局。
2. 开启、重启后仍开启；主题导出/导入与云备份保留设置，旧配置缺少该字段时保留接收设备的当前值。
3. 使用正式 Navidrome 合成服务加载真实 raster 封面，经典、沉浸、声波核、AM 和 AM2 的主封面均出现磁带壳并保留已加载图片；迷你封面不出现。
4. 图片加载失败时仍显示音乐回退符；V02/V03/V04 图片错误处理不变。
5. 切换歌曲后音频、权威队列、匹配录音标题和封面随实际匹配录音更新。
6. 检查减少动态效果与 AX 大字号下开关可达；静态截图只证明外观，连续手势和真机性能不在本规范内冒充完成。
