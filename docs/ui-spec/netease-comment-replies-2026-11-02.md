# 网易公开评论回复展开

本批复用 IPA 离线 E-033→F-032→P-032 的既有评论 Sheet 结构，不新增 Sollin 采集。功能按决策0079逐项验收，布局沿用正式共享组件，不声明像素/动效一致。

- 正常入口：搜索→歌曲更多→歌曲评论。默认主题，iPhone 常态；读取不启动播放。
- 旧状态：网易仅有引用预览，缺少完整回复查询。现有列表不稳定提供 `showFloorComment.replyCount`；未知数量显示“查看回复”，不得捏造“0条”或正数。
- 目标：展开已有楼层、作者头像/可选地区、正文与目标引用；失败保留并同时间游标重试；空回复独立展示；收起/刷新/关闭继续共享取消机制。
- 几何沿用现有36pt根头像、28pt回复头像、14pt回复缩进和至少44pt展开命中区域；不移动Sheet/安全区。先看完整截图，检查回复与错误/分页控件可达、长正文不裁切和固定标题不被内容滚动带走。
- 合成场景：未知计数→首屏→第二页失败保留→相同时间游标重试→收起→另一个根的真实空态；再执行原评论翻页、横屏固定标题、刷新及原生手势关闭。
- 真实场景：公开网易歌曲的热门根评论→匿名floor读取→至少一条真实回复/头像→收起/关闭；原五平台回归按共享标签影响范围验证。
- 精确源码/fixture/bundle/xcresult、截图来源与哈希在阶段报告落账；合成与真实服务证据分别记录。签名、实体机和连续动效仍待验。
