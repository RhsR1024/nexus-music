# 网易云平台歌单删歌 UI 场景

日期：2026-11-18。场景：网易云在线歌曲 → 歌曲操作 Sheet → 从网易云歌单移除 → 选择当前账号创建的歌单。该页面是音枢功能 UI，不是 Sollin 参考页面的像素对齐项；按 0079 以层级、可达、反馈、无裁切和正常操作验收。

## 环境与几何

| 项 | 值 |
| --- | --- |
| 主参考环境 | 1290×2796 截图、430×932pt、3x；iPhone 15 Pro Max 模拟器 iOS 26.3.1 |
| 外层 | 正式 `SheetModal` + `ScrollView`，背景 `palette.background[0]` |
| 内容容器 | `space.lg`（16pt）四边内边距、`space.md`（12pt）纵向间距、`space.xl`（20pt）底部留白 |
| 标题区 | 横向布局，标题 `typography.title`（22pt/28pt）；说明 `typography.caption`（13pt/19pt） |
| 返回按钮 | 最小高度 `controls.hit`（44pt），水平 `space.md`，`radius.md`（12pt） |
| 歌单行 | 最小高度 `controls.hit + space.md`（56pt），水平 `space.md`，垂直 `space.sm`，`radius.md`，hairline 边框 |
| 状态文字 | `accessibilityLiveRegion=polite`，加载/错误/空态均位于滚动内容内 |
| 父入口 | 歌曲操作动作行最小高度 56pt；“添加到网易云歌单”和“从网易云歌单移除”各为独立动作行 |

删歌复用加歌的最小布局，只替换动词、标题、说明、动作标签和错误文案。没有新增第二个账号目录、第二套主题或截图专用页面。

## 验收状态

| 状态 | 期望 |
| --- | --- |
| 删歌入口 | 在线网易云歌曲且恰好一个网易云账号时显示“从网易云歌单移除” |
| 加载 | 显示活动指示和“正在读取或更新网易云歌单…”；返回按钮暂时禁用 |
| 列表 | 只显示当前账号 `kind=created` 的歌单；标题、曲目数、移除动作完整可读 |
| 空态 | “当前账号还没有可移除的网易云歌单”，不伪造目标 |
| 读取失败 | 明确错误和“重新读取歌单”，不保留旧列表作为可操作目标 |
| 回读确认 | 成功返回父 Sheet，显示“已从「…」移除”；`code:200` 不单独作为成功 |
| 幂等 | 目标不存在时显示“这首歌不在「…」中”，不增加写入 |
| 写入拒绝 | 显示“网易云音乐拒绝从歌单移除，请检查账号权限”，列表仍可重试 |
| 未确认/未知 | 提示可能已提交但未确认，要求重新读取核对，不自动重发写入 |
| 登录/账号变化 | 分别提示重新登录或重新打开歌曲操作，不显示成功 |
| 取消 | 退出子视图或切歌后迟到响应不能发布成功 |

## 最终截图

最终 Release `SourceUITests-1794984241898` 的 11 张 1290×2796 截图位于 `build/ui-netease-playlist-tracks-screens-20261118-r9/`：

- `011`：父歌曲操作 Sheet 的加歌入口。
- `005`：同一 Sheet 的删歌入口。
- `010`：当前账号创建的 Synthetic Target Playlist，2 首。
- `009`：回读确认后的加歌成功状态。
- `008`：重复加歌后的幂等状态。
- `007`：加歌写入拒绝。
- `006`：加歌拒绝后重试成功。
- `004`：回读确认后的删歌成功状态。
- `003`：重复删歌后的幂等缺席状态。
- `002`：删歌写入拒绝。
- `001`：删歌拒绝后重试成功。

`006` 与 `009` 字节相同；`001` 与 `004` 的父 Sheet 滚动位置/成功状态相同但不强制同字节，分别对应重试与首次成功断言。该重复不冒充两个独立视觉状态。
