# 系统音频输出路由入口

本批对应 S10 中“系统输出路由入口”的可独立实现部分。正式“播放与歌词 → 播放控制”卡在 App 音量说明之后显示“系统音频输出”，右侧嵌入 Apple `AVRoutePickerView`。AirPlay、蓝牙、耳机和可用设备列表由 iOS 按当前系统状态提供；音枢不维护第二套设备列表、不读取或保存路由凭据，也不改变单一权威音乐队列。

场景固定为 430×932pt / 1290×2796px @3x 的 iPhone 15 Pro Max 模拟器、正式生产入口、默认 blush + rose 主题、正常底栏与设置导航。入口使用至少 44pt 的触控/无障碍区域，检查标题、说明、系统图标、正常滚动、前后台恢复与终止重启后的可达性。截图必须绑定精确源码、构建、xcresult、安装 bundle 与 provenance。

模拟器可验证原生 `AVRoutePickerView` 已渲染、可访问、可被页面生命周期恢复；若没有受支持的 AirPlay/蓝牙/耳机接收端，不点击列表冒充成功，也不宣称设备切换、拔出暂停、来电中断或 iOS 27 真机行为通过。系统路由面板的视觉和可用项以实际设备为准，本批不设置与 Sollin 的像素相似度目标。
