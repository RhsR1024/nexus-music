# 定制风格化推荐：功能与界面场景

本规格覆盖发现页的“定制风格化推荐”。功能语义来自固定 Sollin iOS 2.0.0 build 60 的离线静态证据 `E-056 / F-047 / P-047 / WI-021`，交互补充来自 T7 Android 实机采集。Android 画面只用于检查层级和状态，不能写成 iOS 运行时等价；本规格也不推断或探测 Sollin 的私有推荐请求、账号画像或排序模型。

## 范围与来源

- iPhone 常态目标为 430×932pt；正式证据使用 Release、正常底栏进入发现页、默认 `blush` + `rose` 和公开网易云协议夹具。
- Android 参考图均为 1080×2340 PNG：`273-style-tags.png` SHA-256 `c7cd1e155f4ad025edbe1762352098f6073396e00e702aeb1b08a1769877494c`，`274-style-dimension.png` SHA-256 `df19d3b37b9c8c5d70309256283789aa34bf482d161eb1e4906a35c63d724ac5`，`276-style-sheet-back.png` SHA-256 `b1fa33985d7ca8e9c7ad72de87cd9038ec6c4ae0e4aff7abf836c8fa60cac62d`。
- 参考规格来自 `/Volumes/T7 Touch/NexusMusic/SollinCapture/work/sollin-android-ui-20261023/report/ANDROID_MUSIC_FUNCTION_SPEC.md` 的“风格化推荐（E273、E274）”段及同目录 XML；原始采集与大型素材继续留在 T7。
- 音枢只用网易云公开分类与公开歌单目录。结果按平台和歌单 ID 去重，命中标签数优先；不把公开目录聚合描述为 Sollin 私有推荐服务、个人画像或服务端个性化模型。

## 参考量测

Android 采集窗为 1080×2206 内容像素，系统导航栏另占 134px；以常见 3x density 约合 360×735dp。以下只记录采集可见几何，不直接换算成 iOS pt：

| 区域 | 参考边界/尺寸 | 可复用语义 |
| --- | --- | --- |
| Sheet 顶边 | y=471，左右置零，顶部圆角约 42px | 下半屏 Sheet；背景 discover 保持可见并被遮罩 |
| 头图/标题 | 图标约 100×100px；标题基线在 y=682–748px | 左侧推荐图标、两行标题说明、右侧 44dp 级关闭按钮 |
| 推荐维度 | x=50–1031px，y=840–994px，高 154px | 单选下拉入口；点开后列出五个互斥维度 |
| 标签网格 | 两列，单格约 476×132px，列/行缝约 28px | 标签是主要操作面，计数在标题行右侧 |
| 固定操作栏 | 底部高约 75px，清空/取消/生成三段 | 清空弱化，取消文字操作，生成是低对比禁用胶囊 |

## 状态与验收

| 状态 | 触发与内容 | 可见行为 | 验收 |
| --- | --- | --- | --- |
| 入口 | 发现页已有歌单、榜单、分类内容上方 | “定制风格化推荐”卡片说明公开标签与最多 5 个的上限 | 正常底栏和滚动均可到达，入口不只存在于截图夹具 |
| 分类读取 | 打开 Sheet | 出现加载文案和“取消读取” | 取消后显示可重试状态；迟到分类不得覆盖当前代次 |
| 维度选择 | 分类成功 | 曲风、语种、情感、主题、场景可选择；无标签维度禁用 | 五维来自公开分类映射，切换只改变当前标签列表 |
| 空选择 | 0/5 | 清空和生成禁用 | 不得发出歌单目录请求 |
| 选择/移除 | 点击标签或已选芯片 | 计数即时更新；第 6 个唯一标签禁用 | 去重、移除和清空保留同一选择集合 |
| 生成中 | 至少 1 个标签后生成 | 显示“正在生成…”和取消 | 取消中止所有标签请求；迟到结果不得发布 |
| 部分失败 | 部分公开分类失败 | 成功结果保留，显示失败标签与脱敏提示 | 不能把部分失败写成全量成功或全量空结果 |
| 空结果 | 全部成功但无歌单 | 独立空态文案，不伪造推荐 | 调整标签后可再次生成 |
| 结果 | 去重后的公开歌单 | 封面、标题、命中标签、命中数和首数 | 多命中歌单排序在前，命中理由全部保留 |
| 打开歌单 | 点击结果 | Sheet 关闭，进入既有公开歌单详情 | 返回歌单广场；歌单不进入唯一播放队列，直到用户在详情主动播放 |
| 关闭/重开 | 关闭按钮或系统返回 | 所有在途请求取消 | 再开时选择归零，分类重新读取 |

## 视觉与交互约束

- 头部、计数、标签和底部生成操作必须同处实际 Sheet；关键触控目标不小于 44pt，长标签可换行但不能挤出屏幕。
- 维度控件在 iOS 上可以使用五段标签栏，保留比原版下拉更直接的一步切换；必须保持层级、选中态和计数清晰，若视觉密度或滚动位置影响操作则再收敛。
- 底部“生成推荐”不应包住结果区；结果与失败状态放同一滚动内容，避免固定栏遮住可操作项。
- 动画、连续拖动和页面转场没有同态参考录屏时不报告“一致”；只记录 Sheet 打开、关闭和选择的静态/功能证据。
- 结果只包含公开平台来源和公开目录字段；不采集账号画像、不发送私人令牌、不持久化“推荐结果”为新的权威队列或歌单。

## 本批验收入口

正式用例为 `NexusMusicUITests/SourceSettingsTests/testStyleRecommendation`。本地协议夹具覆盖分类取消/重试、五维、0/5 到 5/5、第 6 个禁用、清空、生成失败、空结果、生成取消、单标签失败保留其余结果、多标签去重排序、命中理由及打开既有歌单详情。详细 build/xcresult、截图和人工检查结果在阶段回执中补录。
