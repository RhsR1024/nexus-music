# 评论作者身份与地域场景

2026-11-01，F31 只读评论纵向增量。场景来源为现有公开评论能力与产品记录中已经观察到的头像、昵称、日期和地区信息；Sollin 既有评论证据 E-033→F-032→P-032 只证明固定 Sheet、刷新、热门/最新分区与列表结构，不证明参考实现中的头像尺寸、地域文案或精确像素。

## 场景

1. 正常评论：列表行展示圆形作者头像、昵称、可选地域、正文、日期和点赞数；缺失头像时显示昵称首字符，不显示伪用户图。
2. 回复行：展开后的回复沿用相同身份层级，但头像缩小以保持线程缩进和正文可读性。
3. 异常数据：不能规范为 HTTPS、带 URL 用户信息、含控制字符或超长的头像/地域字段被丢弃；正文、昵称、回复和分页行为不受影响。
4. 已知边界：平台未返回地域时不补造；头像远程加载失败时保留明确回退，不改变评论区状态或播放队列。

## 布局与交互

- 根评论头像目标 36pt，回复头像目标 28pt，圆形裁切。
- 头像与正文间使用现有 `space.md`（12pt）；昵称和地域可在窄屏换行，正文保持最小宽度，不横向溢出。
- 昵称、地域、正文、日期/点赞继续使用当前主题和动态字体；头像作为装饰元素，不重复无障碍朗读作者名。
- 刷新、加载更多、展开回复、重试和关闭的现有 44pt 操作区域、失败留旧、同游标重试、取消与播放隔离保持不变。
- 本场景先扩展已实现的功能字段；没有同尺寸参考截图，因此不增加静态像素完成量，也不宣称 Sollin 精确还原。

## 验收

- 协议检查：五平台公开响应只在存在合法公开字段时产生头像和地域；危险 URL、控制字符、过长文本被过滤。
- 合成 Release UI：正常评论显示可查询的头像容器、昵称和地域；头像失败时首字符回退可见；热门/最新、分页、刷新、回复、空态和关闭后不播放保持。
- 真实匿名 UI：至少在本次可用的公开源上确认昵称/地域结构与头像容器实际出现；真实用户内容截图只留本机忽略目录。
- 来源、xcresult、截图、源码摘要、本地 unsigned IPA、iOS 27 云端、真机签名与完整来源矩阵分别记录，互不替代。
