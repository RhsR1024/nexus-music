# 酷狗公开评论功能验收

复用现有正式评论 Sheet，不修改布局、图标或动效。iPhone 常态下检查可读、反馈和操作可达，不新增像素对齐完成量。

合成协议场景从酷狗正常搜索进入歌曲菜单：热门/最新、原曲总数、长文本及引用根评论归属；分页首次失败保留旧内容，同页重试追加且总数更新；刷新失败保留后，明确零条响应替换为空态；关闭无播放副作用。夹具仅验证状态压力，不作为默认主题颜色评分。

真实场景使用生产入口、真实匿名搜索与官方 HTTPS 网关。首屏热门、正总数、实际滚动可见的最新分区及第二页追加分别断言。已知服务可能过滤部分评论，首屏实测18行，故要求实际正数首屏和第二页新增，不把请求 pagesize20 误作每页必返20的保证。标题和原曲平台须匹配正常搜索目标；关闭后不触发播放。

固定头部、正文/长文本、引用根评论、分区与分页按钮按实际截图亲看；标准表情字形另记，不能替换用户原文制造通过。每轮使用新输出目录、精确 xcresult 和源码/原生/JS 包摘要，截图导出后逐张校验来源。真实昵称/正文只留本机忽略目录。

HTTPS 网关固定 `x-router`，不关闭证书校验、不扩 ATS、不复制参考静态设备标识。匿名临时 mid 仅存请求内，账号 token/Cookie/播放元数据不参与请求；播放换源不替换原曲评论身份。完整回复展开、写操作、真机/签名和动效分别待验。
