# 酷狗公开评论回复展开：交互与布局场景

2026-11-01，F31 增量。本场景复用已严格审核的评论 Sheet `E-033 → F-032 → P-032`，只增加回复线程，不改变 Sheet、固定标题、刷新、热门/最新分区或系统下滑关闭。

| 状态 | 同内容条件 | 行为与布局 | 验收 |
| --- | --- | --- | --- |
| 根评论有回复 | 酷狗公开接口返回 `reply_num > 0` | 日期/点赞行后显示 44pt 高的“查看 N 条回复”按钮 | 真实数量、可点击、无自动播放 |
| 展开中 | 同一原曲与根评论 | 在线程缩进区显示载入状态；主评论列表保留 | 切换歌曲、刷新和关闭会取消在途请求 |
