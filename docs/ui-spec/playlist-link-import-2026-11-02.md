# 公开平台歌单链接导入：交互与状态规格

2026-11-02，F12/F13 增量。页面沿用正式“发现”页现有的歌单导入区域、默认浅色主题和全局材质，不新增参考视觉等价声明。本规格覆盖链接清洗、网易官方短链异步展开、取消、失败、重试、空歌单，以及原有发现详情的刷新/分页失败保留。

| 状态 | 触发与内容 | 可见行为 | 验收 |
| --- | --- | --- | --- |
| 未输入 | 展开“歌单导入”；输入为空 | 预览按钮保持禁用 | 输入框有稳定标识，按钮不可误触 |
| 直接链接或 ID | 粘贴官方公开歌单链接，或所选平台的纯数字 ID | 不做短链网络请求，直接进入详情 | 长数字 ID 保持字符串；平台不匹配、凭据、非公开端口或欺骗域被拒绝 |
| 短链解析中 | 粘贴 `163cn.tv` 官方短链并预览 | 输入暂时锁定，出现“正在解析分享链接…”和“取消解析” | 解析有 12 秒上限；短链请求不携带凭据 |
| 取消解析 | 点击“取消解析” | 当前短链请求中止，显示“已取消解析。”；迟到响应不得替换当前页 | 输入重新可用；旧解析代次和导航均被隔离 |
| 短链失败 | 连接失败、超时、服务拒绝或响应无效 | 使用固定脱敏文案，建议展开完整链接或重试 | 不回显 URL、原始异常或令牌；再次预览可恢复 |
| 空歌单 | 公开详情返回明确 0 首 | 显示“此歌单为空，无法导入。”；完整导入按钮显示“歌单为空”并禁用 | 空态不是错误；刷新仍可用 |
| 刷新/分页失败 | 已有内容时刷新或“加载更多”失败 | 保留当前歌曲、筛选与数量，显示脱敏错误和重试 | 重试沿用原刷新或下一页目标，不清空内容 |
| 完整读取 | 已有歌曲满足完整导入前置条件 | 仍进入原有完整读取、取消和确认流程 | 数量不完整时不弹确认，原音乐库保留 |

本批截图来自 iPhone 15 Pro Max、iOS 26.3.1 模拟器。测试只使用合成链接、歌单和账号标识。该规格不把动效、真实弱网矩阵、实体机、签名或 iOS 27 云端记为通过，也不声明与 Sollin 的视觉或交互完全一致。
