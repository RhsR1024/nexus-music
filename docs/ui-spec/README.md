# 黄金态规格与视觉实验室

**操作与验收以 [UI_ALIGNMENT_WORKFLOW](../UI_ALIGNMENT_WORKFLOW.md) 为准。** 本目录保存场景规格与测量摘要，工具通过只代表声明区域达到初始门槛，不代表整页或交互达到90%。先4855/4856样板，再4854经典；默认blush/rose与iPhone常态范围不变。

## 工具做了什么

| 输出 | 实际含义 | 不能证明 |
| --- | --- | --- |
| 7×7局部SSIM | 亮度、对比、内容和局部结构的综合相似度 | 纯几何准确、字体正确、开发完成百分比 |
| CIEDE2000 | ICC归一到sRGB后，Lab D65色差分布 | 小块采样通过即全页配色通过 |
| Sobel相关与密度 | 同位置边缘/笔画分布的比较；也受文案和换行影响 | 字体识别或消除内容差异 |
| 内容占比与条件估算 | 固定当前非内容区得分，假设内容区完美的加权估算 | 整页可达上限或90%不可实现 |
| 网格、色块、并排/色差图 | 定位局部偏差 | 关键区域自动验收、人工观感或动效验收 |

`ceilingIfContentMatched` 是历史字段名，不改历史JSON；其公式忽略窗口跨边界和封面改变背景取色的联动，必须按“条件估算”解释。`pass` 是工具局部结论；状态、指标缺失、区域覆盖、正常入口、几何和人工审查仍须单独核对。

参考图中有Display P3/16bit，`visual-lab`使用macOS `sips` ICC→sRGB 8bit转换后计算，保存原图/转换后SHA。旧 `scripts/visual-diff.mjs` 仅作历史灰度对照，不作为当前颜色或独立验收证据。

## 场景与区域

现有JSON记录参考/候选路径与SHA、尺寸、主题/背景/播放/滚动说明、排除区、色块和初始阈值。`state`是描述数据，脚本没有自动证明实际截图处于该状态；须用采集断言、画面和构建来源核实。

`contentMasks`/`controlMasks`是排除区；未提交候选工具还在扩展包含区域/独立颜色区域。无论采用哪种形式，必须报告**相对于完整应用画面**的控件/颜色覆盖率，以及每个ROI内部的排除率；不能把ROI内部100%覆盖称整页覆盖。标题、主题选项、Sheet容器、歌词排版、背景取色不能作为“不同内容”整体豁免。

默认初始阈值仍为控件区SSIM≥0.90、平均ΔE00≤4、边缘相关≥0.35。它们需要已知错位/错色/错图标反例校准，并结合关键区、pt锚点和人工结论；所有指标齐全且达标仍不足以宣布整页完成。遮罩变更必须版本化并重算旧候选，不能边改产品边缩区域凑分。

## 安全重算

从项目根执行，显式指定单态和新输出目录。下面只重算规格中已绑定的图片，不会重新采集App；不通过返回非零是正常负结果：

```bash
source scripts/environment.sh
ui_audit_dir="$(mktemp -d "$PWD/build/ui-lab-XXXXXX")"
node scripts/visual-lab.mjs --spec docs/ui-spec/4855-appearance.json --out "$ui_audit_dir/4855"
```

已提交基线 `2bc2a63` 的 `--all` 会把 `repro-*.json` 纳入规格；当前工作树有过滤修正，尚未因本次文档更新完成验收。复测旧基线时显式逐个 `--spec`，不要靠 `--all` 推断复现成功。`npm run visual:lab` 本身带 `--all`，后接 `--spec` 不等于只运行一态。

正式结果不得使用默认可覆盖输出目录。`--baseline`写出新清单，不是比较命令；不得覆盖已冻结baseline。`--candidate`覆盖时须自行绑定新候选/构建/哈希，规格内旧候选SHA不会替它校验；`--skip-hash`只能探索。原始截图和报告留本机忽略目录，仓库只留脱敏规格/摘要。

## 复现证据的范围

指标复算与App重新采集分开记录。同一冻结输入重算只能验证指标稳定，不能证明当前代码或实际渲染稳定。

历史 [经典复现](repro-classic-2026-10-21.json) 和 [黑胶复现](repro-vinyl-2026-10-21.json) 表明两对指定截图在排除状态栏后逐像素一致；不外推到新播放态、其他页面、OS或新采集方法。每个新场景需两次独立采集，记录实际噪声和稳定条件。

`visual-repro.mjs`没有复用ICC归一流程；只直接比较已确认同色彩空间/位深的截图，跨格式先统一颜色管理。几何锚点自动测量、状态强断言、覆盖率门禁、自动叠图、不可覆盖保障、人工/录屏签核和完整视觉CI仍需逐项实施或人工执行，不能由工具`pass`替代。
