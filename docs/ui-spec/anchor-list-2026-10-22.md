# 4855/4856 锚点清单 v1（冻结 2026-10-22）

## 测量口径

- 参考与候选均为 1290×2796、430×932pt（3x）；参考经 `sips` ICC→sRGB 8bit。
- 墨迹 bbox：RGB 三通道低于逐项标注阈值（120/140/160）；图标：与窗口局部背景众数欧氏距离 >30。坐标 3x→pt，末位约 0.33pt 为像素量化。
- 参考为照片截图，文字/图标边缘噪声约 0.3–0.67pt；≤0.67pt 不作通过依据，>1pt 才记缺陷。窗口边缘被裁切的 bbox 只比较未裁切方向。
- 脚本与运行参数：`build/ui-method-r9-20261022/anchors-4855.mjs`（选中底色/三个标签）、`measure-icons.mjs`（三个图标）、`bbox.mjs`（行标签/值/图例/头部墨迹）、`probe.mjs`（Sheet 顶边）。本清单全部数值可用这些脚本和冻结 PNG 重算。

## 使用与披露

- r15 起 4855 的 D1 最差项仍为 A6 纯色标签左缘 +1.00pt（≤1.0 档 → D1=100），**S=94.00，静态对齐保持**；4856 D1 最差为 B3a 左缘 −1.00pt（≤1.0 档 → D1=100），**S=97.50，静态对齐保持**（G5/G8 待验）。**Phase 0 静态对齐 2/5**。A5 渐变宽度缺陷已清零并保持标签零位移；4855 D3 只剩 A2 标题墨迹宽 +4.00/可见高 +1.00 一项 minor（D3=90）。A2/A2b/B1h 中心误差 ≤0.50pt，不触发 D1 扣分。
- r14 时 4855 S=92.00（D3=80：A2+A5）、4856 S=97.50；r15 只改渐变字形后 4855 S=94.00（D3=90），4856 除时钟外零差异。r15 回执见[渐变图标墨迹宽](appearance-segment-glyph-r15-2026-10-22.md)；r14 标题/图例见[标题缩进与图例字号](appearance-typography-r14-2026-10-22.md)；r13 行几何见[视觉参数行几何](appearance-rows-r13-2026-10-22.md)；r12 分段字形见[字形回执](appearance-glyph-r12-2026-10-22.md)。下一次产品像素修改必须引用本清单，并在同一采集目标下复测。
- B2 左缘 40.00 为冻结窗口（x 40..130）裁切值；r13 用 30..130 窗口复测，参考与候选真实左缘同为 32.67pt，右缘 103.00/102.67pt，与表内宽度差一致。B3/B4 数值使用冻结窗口与 RGB<140 墨迹阈值，参考/候选同脚本重算。
- r13 同一脚本重算参考值，归一 r10 逐项阈值造成的像素裁边：B2c/B2d 右缘 88.33→88.00（宽 48.33→48.00）、B3a 左缘 358.00→358.33、B4a 上缘 710.00→710.33/高 11.00→10.67。对 D1 带宽无影响；B4a 高度缺陷由 +0.67 变 +1.00（更严）。
- 图标家族已由 IPA 字体子集交叉核对为 CupertinoIcons：参考对应 `circle_fill` (f400)、`layers_alt_fill` (f8e7)、`photo_fill` (f768)，三个码位都在 Sollin 的 Cupertino 子集中，Material 子集不含对应字形。r10 回执的“SF Symbols 家族”措辞据此更正；r12 已落地这三个码位。
- 未覆盖锚点：色块/材质采样点、滑轨端点、主题行距。冻结规格内没有声明色块 ROI；D4 暂只按关键区的均值/p90 评级，不声明“色块最大值达标”。待下一次冻结规格升版时补齐。
