# 4855/4856 锚点清单 v1（冻结 2026-10-22）

本清单是[页面相似度量表](page-similarity-rubric-2026-10-22.md) D1 的冻结锚点，覆盖 4855 外观顶部与 4856 外观滚动下段。冻结后不再因结果回调；后续修改按新清单升版，并在回执中给出新旧差异。

## 测量口径

- 参考与候选均为 1290×2796、430×932pt（3x）；参考经 `sips` ICC→sRGB 8bit。
- 墨迹 bbox：RGB 三通道低于逐项标注阈值（120/140/160）；图标：与窗口局部背景众数欧氏距离 >30。坐标 3x→pt，末位约 0.33pt 为像素量化。
- 参考为照片截图，文字/图标边缘噪声约 0.3–0.67pt；≤0.67pt 不作通过依据，>1pt 才记缺陷。窗口边缘被裁切的 bbox 只比较未裁切方向。
- 脚本与运行参数：`build/ui-method-r9-20261022/anchors-4855.mjs`（选中底色/三个标签）、`measure-icons.mjs`（三个图标）、`bbox.mjs`（行标签/值/图例/头部墨迹）、`probe.mjs`（Sheet 顶边）。本清单全部数值可用这些脚本和冻结 PNG 重算。

## 使用与披露

- r12 起 4855 的 D1 最差项为 A6 纯色标签左缘 +1.00pt（≤1.0 档 → D1=100），4855 **S=92.00，记静态对齐**（G5/G8 待验）；4856 D1 最差仍为 B4a 遮罩图例 3.00pt（B4b 2.00pt 次之），S=71.00。A2/A2b/B1h 中心误差已 ≤0.50pt，不触发 D1 扣分。
- 本清单冻结时，三个分段图标的字形替换尚未进入 r11 候选（r10 属于诊断基线，不是实施前后对照）。r12 已改用官方 `cupertino_icons` 包字体资产（非 IPA 二进制）并完成实测，见[字形回执](appearance-glyph-r12-2026-10-22.md)；r11 页头实测见[页头回执](appearance-header-r11-2026-10-22.md)。下一次产品像素修改必须引用本清单，并在同一采集目标下复测。
- 图标家族已由 IPA 字体子集交叉核对为 CupertinoIcons：参考对应 `circle_fill` (f400)、`layers_alt_fill` (f8e7)、`photo_fill` (f768)，三个码位都在 Sollin 的 Cupertino 子集中，Material 子集不含对应字形。r10 回执的“SF Symbols 家族”措辞据此更正；r12 已落地这三个码位。
- 未覆盖锚点：色块/材质采样点、滑轨端点、主题行距。冻结规格内没有声明色块 ROI；D4 暂只按关键区的均值/p90 评级，不声明“色块最大值达标”。待下一次冻结规格升版时补齐。
- 参考图中被 Sheet 裁切的标题/箭头只比较可见上缘，不推测被遮挡部分。
