# 4851 黑胶播放态锚点清单 v1（冻结 2026-10-23）

本清单是[页面相似度量表](page-similarity-rubric-2026-10-22.md) D1/D2 在 4851 上的冻结锚点与关键区声明。冻结后不因结果回调；后续修改按新清单升版，并在回执中给出新旧差异。

## 测量口径

- 参考与候选均为 1290×2796、430×932pt（3x）。参考 `resource/reference-ui/sollin-2026-10-18/IMG_4851.PNG`（SHA-256 `6b241210bc815be92d0a931aac9c2867e6e82cfaaab5ec8c114325809e0e92f8`）经 `sips -m sRGB` 转 8bit 后量测，转换副本 SHA-256 `3445f0ce51c63c086f4706f7378c225eaada0aad4ed3efc7d9f9e8975c4db466`；候选为同源码 Release 采集的 8bit sRGB PNG。
- 墨迹阈值：标题/歌手/工具图标/上一首/下一首 RGB 三通道均 <160；播放圆钮 <170；进度条已播放段与拇指 <200；未播放尾段 <240；暂停条为圆钮内三通道均 >180 的亮墨。坐标 3x→pt，末位约 0.33pt 为像素量化。
- 黑胶盘面（deck）边界：逐行统计亮度 <80 的连续暗带，取覆盖 >700px 且列覆盖 >50% 的带；顶行 467、底行 1520、左列 89、右列 1200。圆角半径按顶行暗带起点随行下移的圆弧拟合，r≈51px=17pt。
- 唱片中心/直径：在盘面内以亮度径向梯度拟合外缘，避开唱臂象限；拟合 (570,1016)px、r=450px。标签以颜色边缘拟合 (570,1016)px、r=209px。
- 进度拇指：在拇指邻域按列统计暗像素，列高 ≥20px（6.67pt，进度线仅 5pt）的列定义为拇指，取列区间中心。播放进度端点即拇指中心。
- 脚本：`build/measure-4851-20261023/measure-deck2.mjs`（盘面/唱片/标签）、`measure-rows.mjs`（标题/进度/传输/工具/脚注墨迹）。全部数值可用脚本与冻结 PNG 重算。
- D1 只用**布局锚点**（位置/中心/轨道端点/行 y）。图标墨迹宽高与内部笔画归 D3 记账（D1 以中心/左缘判定，字形尺寸与宽度缺陷记 D3），避免同一字形缺陷在 D1/D3 重复扣分。
- 状态：iPhone 常态、`blush + rose`、light、`solid`、播放中 32.9%（夹具 seek 93.5/284，与参考 01:33/04:44 同秒；截屏后恢复暂停）、fontScale 1、zh；参考 01:33/04:44=32.86%。
- 参考与候选的**音质脚注文案**为内容差异（参考“安妮独家音源 · FLAC”，候选实际“ORIGINAL 音源”（r7亲看纠正旧记录“FLAC 音源”）），D5=75；标签封面为同一 924px 裁剪，但唱片在播放中旋转，标签朝向相位为动画相位差异，声明为 D5=75 的一部分，D2 以标签矩形遮罩排除。参考与候选的标题、歌手、心形、时间数字字符串一致。
- 候选左上“收起播放页”箭头是音枢可达性扩展，参考无此控件，冻结为**声明性产品扩展**，不计入 D1/D3；其位置在 `ignoreTop` 邻域，回执中披露其可见范围。

## 使用与披露

- 本清单冻结的是锚点元素、参考值、量测方法与关键区，不冻结候选结果。候选列在本轮采集完成后回填，偏差按最差项计。
- 候选结果若暴露新的控件级差异，按 D3 记缺陷；若暴露新的布局级差异，先按本清单量测，只有缺失/错层/遮挡/裁切或 >5pt 才触发 D1=0。
- 未覆盖锚点：盘面渐变的具体色带形状、沟槽纹理细节、唱臂内部光影；这些记入 D4 色块/材质与 D3 字形/控件缺陷，不进入 D1。
