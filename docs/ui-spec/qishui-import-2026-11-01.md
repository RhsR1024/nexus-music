# 汽水公开歌单导入：交互与布局场景

2026-11-01，F12/F13 正式 App 回归。页面沿用当前音乐库、汽水导入 Sheet 和默认主题，不新增参考像素门槛；本场景验证已有入口、正式保存和重启恢复。

| 状态 | 同内容条件 | 行为与布局 | 验收 |
| --- | --- | --- | --- |
| 未读取 | 用户打开“汽水歌单导入” | 顶部为展开按钮与标题；说明明确“不登录汽水、不直接播放”；长数字 ID 输入与读取按钮纵向排列 | 44pt 目标、输入完整、读取在空值时禁用 |
| 读取中 | 首个公开页被夹具挂起 | 读取按钮进入载入态，出现独立取消按钮；说明和输入保留 | 取消可达，取消后读取重新可用 |
| 完整预览 | 两页合计 3 条且含重复 | 自动带出歌单名；显示“完整读取 3 条 · 保留重复项 · 作为新歌单追加”；下方按 `one, two, one` 展示原序预览 | 总数、重复项、原始顺序和“待匹配”可见 |
| 保存成功 | 用户确认追加 | 消息区显示“已追加导入 3 条，原始歌曲保留；播放时匹配其他平台。”；预览清空，仍可收起 | 只创建正式音乐库歌单，不启动播放或替换歌曲 |
| 歌单详情 | 返回音乐库并打开新建歌单 | 标题与三行歌曲按原序展示，重复项保留；行副标题为“Fixture artist · 汽水 · 待匹配” | 可点行、数量正确、Y 坐标严格递增 |
| 重启恢复 | 终止并重新启动 App | 同一歌单仍存在，再次打开得到相同三行与原序 | 顺序、重复项、原曲平台和待匹配状态不丢失 |

本批截图来自 iPhone 15 Pro Max、iOS 26.3.1 模拟器，默认浅色主题。该规格不新增静态视觉完成量；动效、实体机布局和真实服务外形仍单列。
