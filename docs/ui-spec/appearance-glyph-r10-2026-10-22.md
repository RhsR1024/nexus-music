## 评分严格性说明

按当前量表，D3=0 时即使 D1/D2/D4/D5 全满分，S 上限也只有 80。要达成 S≥90，必须同时满足：D1≥90、D2=100、D4≥90、D5≥90，且 D3≥75（最多一项 major、其余仅 minor）。因此三枚分段图标替换为参考的 SF Symbols 家族、并把尺寸/字距收敛到 1pt 内，是不可绕过的门槛，而不是可选优化。
