## 改动前缺口

音乐库首页单独实现的Sheet只有下一首/入队/收藏/加歌单/匹配及集合管理动作，缺少已有通用组件的分享、下载、相似歌曲等。完整列表没有批量下一首、批量下载或通用更多入口。选择身份按条目ID维护，但批量提交始终按存储顺序，未跟随用户选定排序。

## 预定状态与验收

1. 首页和完整列表歌曲更多复用共享菜单；歌单上移/移除与历史删除保持可达。集合收藏继续操作音乐库成员；本机音频收藏flag与集合职责分开。
2. 批量下一首将选中歌曲按当前排序插入当前曲之后，保留当前曲、暂停意图和重复条目；筛选只改变可见集合，已选但暂不可见条目仍计入已选总数，按同一排序处理。
3. 批量下载使用既有提交服务，逐项呈现受理/已有/失败及任务真实状态；失败保留选择供重试，成功清除选择。关闭/更换列表后旧异步结果不得重开结果页。
4. 收藏集合批量移除明确显示取消本地收藏；歌单和历史使用各自移除文案，确认框仍只修改本地集合。
5. 在正式Release中验证筛选排序后两首保序插队、当前曲不变、下载逐项回执、分享取消后菜单及暂停状态、重复条目精确删除及重启保持。
