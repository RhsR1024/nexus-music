# J29 自定义睡眠滚轮有效输入

音枢自有有效输入规则：自定义时长须大于零，0小时0分钟显示“请选择至少1分钟”，保留现有原生截止时间或本曲绑定；只有明确取消入口使用零秒取消。有效时长沿既有原生睡眠服务启动。完整设置页既有1–1440分钟校验作为一致性依据，不推断Sollin原版零值行为。
