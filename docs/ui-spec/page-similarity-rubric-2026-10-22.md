# 页面相似度评分量表（v1，冻结 2026-10-22）

本量表是 [UI_ALIGNMENT_WORKFLOW](../UI_ALIGNMENT_WORKFLOW.md) 要求的“预先评分量表”。在用于任何页面之前冻结于此；权重、参照等级、门禁与证据规则一经使用不得回调。没有按本量表计算的证据，只能报告具体指标和“静态验收项通过/未通过”，不得写“相似度 90%”。

量表不改变既有自动门槛：声明区域 SSIM ≥ 90%、平均 ΔE00 ≤ 4、边缘相关 ≥ 0.35。SSIM/ΔE/边缘仍是诊断量，不是百分比本身。

## 1. 评分单元与状态权重

评分单元是**页面 × 状态**。Phase 0 五态权重固定为各 20%，不因本轮工作调整：

| 状态 | 页面 | 权重 |
| --- | --- | --- |
| 4854 经典播放器（播放中，夹具进度同参考） | 经典播放器 | 20% |
| 4851 黑胶播放器 | 黑胶播放器 | 20% |
| 4855 外观设置（顶部） | 外观设置 | 20% |
| 4856 外观设置（滚动下段） | 外观设置 | 20% |
| 4861 AM 歌词 | AM 歌词页 | 20% |

新增页面/状态只能通过新的冻结清单加入并注明理由；不得对已评分状态追溯改权重。项目“视觉对齐完成度”只累计**静态对齐**的状态权重；“完整 UI/交互完成度”只累计同时通过静态、正常入口交互与范围内动效的状态权重。代码已实现另记，不折算为对齐量。

## 2. 每态维度权重

| 维度 | 权重 | 评什么 |
| --- | --- | --- |
| D1 容器与结构几何 | 25% | Sheet/页面容器、安全区、锚点、控件边界、层级 |
| D2 关键区域静态视觉 | 30% | 预声明关键区的三轴结果与结构性观感 |
| D3 字体、图标与控件细节 | 20% | 字体家族/字重/字号/行高/基线、图标字形/笔画、控件尺寸 |
| D4 颜色与材质 | 15% | 声明色块、边框、透明度、渐变、模糊 |
| D5 内容同态与素材可比性 | 10% | 参考/候选是否同状态、同素材、背景取色可验证 |

`S = 0.25·D1 + 0.30·D2 + 0.20·D3 + 0.15·D4 + 0.10·D5`（各维度 0–100）。

## 3. 维度参照等级

### D1 结构几何

实施前冻结锚点清单（容器边界、标题基线与墨迹、每个控件边界/中心、轨道端点、行距）。锚点偏差按最差项计：

| 等级 | 条件 |
| --- | --- |
| 100 | 所有锚点 ≤ 1.0pt |
| 90 | 最差 ≤ 1.5pt |
| 75 | 最差 ≤ 2.0pt |
| 50 | 最差 ≤ 3.0pt，或一处非关键层级差异 |
| 25 | 最差 ≤ 5.0pt，或多处 2–5pt |
| 0 | > 5.0pt；或控件缺失/多余/错层/遮挡/裁切；或容器模式错误 |

锚点必须来自可复现的像素/墨迹量测（3x→pt），不能用目测。D1=0 同时触发 G2 否决。

### D2 关键区域静态视觉

关键区以实施前冻结的 `criticalRegions` 为准（当前 4855/4856 使用 2026-10-21 容器批次预声明的行级区域；主规格中的窄条是继承自 Phase 0 的诊断 ROI，不替代页面关键区）。每区等权：

- 区域通过 = SSIM ≥ 0.90 **且** 平均 ΔE00 ≤ 4 **且** 边缘相关 ≥ 0.35，且人工观察无缺元素/错位/遮挡/裁切。
- 图标字形错误属于 D3/G3，不在此重复扣分；但因此造成的缺元素或明显错位仍算该区不通过。

| 等级 | 条件 |
| --- | --- |
| 100 | 全部关键区通过 |
| 75 | 通过区权重 ≥ 80% |
| 50 | ≥ 60% |
| 25 | ≥ 40% |
| 0 | < 40%，或任一核心区（容器/主导航/主操作区）失败 |

未通过全部关键区一律触发 G4，该态不得记“静态对齐”。

### D3 字体、图标与控件细节

逐项缺陷记账：字号/字重/行高/基线偏差 ≤ 1pt、AA 灰度差异、图标笔画内部差异记 **minor（10 分）**；字体家族或字重错误、图标字形家族错误（如 MCI 替代 SF Symbols/Cupertino）、字号/尺寸偏差 > 1pt 记 **major（25 分）**。

`D3 = max(0, 100 − 10·minor − 25·major)`；缺文字/不可读/裁切另触发 G2/G3。缺陷清单必须逐条列出元素、参考值、候选值、量测方式。

### D4 颜色与材质

实施前声明色块/材质 ROI（控件色、轨道、卡片、背景、描边、文字墨色），同时报告每个关键区的 CIEDE2000 均值与 p90，避免少量色块取样替代整页颜色结论：

| 等级 | 条件 |
| --- | --- |
| 100 | 所有关键区平均 ≤ 2 且 p90 ≤ 4；声明色块最大 ≤ 4 |
| 90 | 所有关键区平均 ≤ 4 且 p90 ≤ 6；声明色块最大 ≤ 8 |
| 75 | 关键区平均 ≤ 6，或 p90 ≤ 9 |
| 50 | 关键区平均 ≤ 10 |
| 25 | 关键区平均 ≤ 15 |
| 0 | 平均 > 15，或材质/透明度/渐变结论与参考相反 |

不同文案、照片纹理导致的像素色差不得混入材质 ROI；p90 受文字边缘影响时须单独说明并把文字区排除率写进证据。取样点、面积与排除率随证据保存。

### D5 内容同态与素材可比性

| 等级 | 条件 |
| --- | --- |
| 100 | 同状态、同素材（同一封面/歌词/主题），背景取色链路可验证 |
| 90 | 同状态，差异仅在声明的不影响布局区（如系统时钟）或等价密度文本 |
| 75 | 同状态，但布局相关文本行数/封面裁切不同；布局另行量测 |
| 50 | 同状态但在进度/选中/展开度等非结构参数上不同且已记录影响 |
| 25 | 主题/皮肤/背景类型不同 |
| 0 | 参考与候选不是同一状态 |

**D5 < 75 时该态不得报告任何 ≥90% 结论**，无论 S 计算值多少。

## 4. 不可用其他项抵消的门禁

| 门禁 | 要求 | 不满足的后果 |
| --- | --- | --- |
| G1 来源 | 精确 xcresult、构建 SHA/配置、fixture 与规格哈希、候选 PNG 哈希、工具版本齐全 | 不评分 |
| G2 完整性 | 无缺失/多余/错层/遮挡/裁切控件，层级与参考一致 | 静态不通过 |
| G3 字形/文案 | 参考可见区域内无错字、缺字、图标语义错误或整段字体家族错误；单个图标的字形/笔画差异计入 D3，不单独否决；音枢扩展区单列且不覆盖参考区 | 静态不通过 |
| G4 关键区 | 全部冻结关键区通过三轴与人工结构检查 | 静态不通过 |
| G5 正常入口 | 从正式导航完成打开/关闭/滚动/选择/持久化/播放意图，并有运行证据 | 只记“静态对齐，交互待验” |
| G6 音枢扩展 | 扩展主题/功能入口保留且可用；不得为对齐删功能 | 回退该修改 |
| G7 量表稳定 | 本轮不得改遮罩、阈值、参考图；覆盖率相对完整画面与 ROI 内部排除率均报告 | 结果作废，按新版本重算 |
| G8 动效 | 范围内动效需同起点/操作/终点的真实设备录屏；无参考时记“动效待验” | 不记“完整 UI/交互通过” |

“静态对齐”= S ≥ 90 且 G1–G4、G6、G7 通过；“完整 UI/交互通过”另需 G5，范围内动效另需 G8。音枢扩展不参与相似度分子，但保留情况必须逐项记录。

## 5. 逐项证据与计算方式

- D1：`scripts/lib` 的 PNG 解析 + 墨迹/边界量测脚本（每次在回执中给出测量点与坐标）；与参考并排/叠图人工复核。
- D2：`node scripts/visual-lab.mjs --spec <冻结规格> --out <新目录>`；报告逐区 SSIM/ΔE00/边缘与覆盖率，规格副本及哈希随回执保存。
- D3：逐项缺陷表（元素、参考 pt/字形、候选 pt/字形、差值、证据图）。
- D4：声明色块 ROI 的 CIEDE2000 均值/最大值；材质另行记录采样 hex/alpha。
- D5：场景清单（主题、背景类型、进度、选中、展开度、夹具哈希）。
- 所有分数保留两位小数；单态最终写 `S=xx.xx (D1..D5=[…])`，并列出通过/未通过门禁。禁止只写一个“90%”。

## 6. 报告格式

每态结论必须是一行可审计记录：

```
4856 scrolled: S=92.42 (D1=95,D2=100,D3=90,D4=90,D5=100);
G1-G4/G6/G7 pass; G5 pending; G8 pending → 静态对齐，交互/动效待验。
```

## 7. 变更控制

权重、等级、门禁或关键区变化 → 升版 `v2`，写变更理由，冻结新规格并对所有既有候选重算；旧版结果保留为历史，不得混用。任何“为过线”缩小遮罩、调低阈值或更换参考图的操作按 G7 判作废。
