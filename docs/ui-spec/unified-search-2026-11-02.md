# 全局歌曲/专辑/艺术家搜索（实施前登记）

本批补 J25 的统一实体入口。现有歌曲、歌单、专辑、艺术家与 MV 页签及其协调器继续保留；在正常搜索页新增“全部”页签，一次检索歌曲、专辑和艺术家，并按平台分组给出有界预览。歌单与 MV 保持独立页签，不把不同详情或播放语义混入统一结果。

## 场景与边界

- 设备与尺寸：iPhone 常态布局，430×932pt；证据截图 1290×2796px @3x。
- 构建：Release、正常底栏进入搜索；默认外观 `blush` + `rose`，保留实际封面取色与已有背景条件。
- 数据：五个公开平台各自使用现有匿名搜索 provider；私有 Navidrome 继续在“私人曲库”中选择歌曲/专辑/艺术家，避免把服务器地址或凭据送入公开搜索。
- 状态：输入、平台切换、加载、单类型失败、空结果、结束与“加载更多”沿用各自协调器。统一页只显示每平台、每类型的少量预览；独立页签继续显示该类型自己的分页、重试和追加失败保留旧行状态。
- 交互：统一歌曲预览使用现有权威队列；专辑/艺术家打开正式详情；“查看全部”切换到对应类型页签，不建立第二套结果或播放器。

## 结构

- 类型栏顺序为“全部、歌曲、歌单、专辑、艺术家、MV”；全部页签与其余筛选均至少 44pt，使用现有 chip、文字、颜色和最小间距。
- 全部结果按“平台 → 歌曲/专辑/艺术家”嵌套。平台标题明确显示来源；每个实体块显示已载入数量与目录总数（总数缺失时不伪造），最多预览两项。
- 每个实体块提供至少 44pt 的“查看全部”入口。类型切换后保留已经成功载入的其它协调器内容，不因浏览统一页而重置独立分页。
- 长标题最多两行，封面使用现有 `Cover`、64pt 方形规格与现有圆角；MV 不进入本页。

## 验收

- 使用正式搜索页和本地无凭据公开协议夹具验证网易云“全部”查询同时出现歌曲、专辑与艺术家，来源标签、预览和“查看全部”均可达。
- 进入歌曲页签后显式加载第二页，再返回“全部”并进入专辑/艺术家，确认三类内容没有互相清空，详情返回仍回到原搜索结果。
- 使用既有协调器测试证明迟到响应隔离、单平台失败、空页、追加失败和重试；不得以成功编译代替真实公开搜索抽查。
- 截图检查全屏、关键区域、文字换行与触控可达性并亲看。当前 J25 来源为用户清单 `U`，本批不新增 Sollin 结论；没有同态参考录屏时不报告像素、动效或原版一致。
