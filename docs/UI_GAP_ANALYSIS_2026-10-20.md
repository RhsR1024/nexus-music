# 2026-10-20 UI 差距分析与 90% 可行性

本轮先修正度量，再用同一批截图重算基线。结论先行：

- 旧脚本算的不是标准 SSIM。它把整幅图当成一个窗口，用全局均值/方差/协方差算一个数；标准 SSIM 是**局部窗口相似度图的均值**。结果既会把接近的页面压到 20–45%，也会把明显不同的页面抬到 90%。
- 改用 7×7 局部窗口后，9 个已采集状态的真实相似度是 **44.9%–89.7%，均值 67.6%**；**没有一个状态整屏达到 90%**。此前记录的“黑胶 90.62% 已对齐”实测只有 **78.54%**，属于度量假阳性。
- 经典播放页在“除封面外全部像素完美”的上限模型下只有 **86.6%**：参考封面色块（照片）占屏 23.7%，夹具是合成 RGB 封面。**整屏 90% 在该页用当前夹具数学上不可达**，与逆向深度无关；但遮掉封面后的可比区已达 **90.42%**。
- 因此 90% 必须分两口径验收：**结构/控件口径（可比区）≥90%** + **整屏口径记录上限与残差**。整屏 90% 只在无照片内容、且主题状态与参考一致的设置类页面可达（4856 当前 89.68%，距 90 仅 0.3 分）。

## 3. 90% 可行性：仅靠 IPA 逆向够不够

**不够，而且方向不对。** 依据：

1. **IPA 能给的是符号与常量，不是几何。** 当前 IPA 静态恢复覆盖 24,298 个非零函数入口、36,392 条函数边界与 36,928 条名称，能确认视图类、字段名、颜色/曲线常量（E027/E028 等）。但 `RenderBox` 的最终位置由运行时约束、字体度量、动态字体与安全区共同决定；AOT 快照不含某机型上的解算结果。
2. **截图为唯一 pt 级几何真值。** 本项目的有效收敛都来自 3×→pt 量测（如 4856 文本锚点 433.7/528.7/623.7/801.3pt 与参考逐项重合）。纯逆向无法给出这些数值。
3. **素材与内容是产品数据，不在 IPA 里。** 参考封面是照片，夹具是合成 RGB；这直接决定 4854 的上限 86.6%。
4. **动效只能录屏。** 弹簧参数、连续手势、转场曲线无法从静态快照还原；IPA 只能给时长/曲线常量候选，需逐帧比对。
5. **整屏上限已被证明低于 90%。** 即使控件 100% 正确，4854 也只有 86.6%。因此“仅基于 IPA 把 UI 还原到整屏 90%”在数学上不成立。

**可行路径**：截图定几何 → IPA 校验常量/语义 → 录屏定动效；验收用“可比区（遮罩内容）+结构锚点+动效帧”三项，整屏分数同时记录但注明上限。按此路径，设置类页面（4855/4856/4857）可比区 90% 可达；播放类页面可比区 90% 可达，整屏只能到 85–88%。4854 已实测到可比区 90.42%，是本路径的第一个证据。

## 4. 本轮发现的两个证据缺陷

1. **经典页截图被样式 Sheet 遮挡**：测试在点击 `play-skin-classic` 后立即截图，捕获到 Sheet 退场动画，`006-Classic-reference-composition` 实际是“经典页 + 样式表”，与 IMG_4854 比对得到 25.91%（旧）/60.33%（新），不能代表经典页。已改为等待 Sheet 离开层级 + 播放进度条连续两帧稳定后再截图。
2. **历史分数指向已删除附件**：4854 的 76.09% 来自 `build/ui-screenshots/001-...`，该文件已被后续批次覆盖。分数必须与附件哈希绑定；本轮起记录附件路径与 SHA256。
