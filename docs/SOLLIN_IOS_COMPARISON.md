共同设计规则：大留白、大圆角、清晰字重层级；低饱和粉/蓝/米色渐变；封面自适应色；薄描边和半透明模糊层；强调色统一；内容滚动到悬浮控件下方时有足够底部空间。mini 常驻业务页，完整播放页隐藏重复 mini；玻璃效果适配系统能力并有普通模糊/不透明回退。减少动态效果、提高对比度、大字、VoiceOver 和长文本均需可用。

一个权威队列与播放意图，五种播放器皮肤共享同一播放状态，不各自创建播放器。PCM 不逐帧进入 React state；歌词使用有界可见区域和原生动画。截图不证明 Live Activities/灵动岛扩展已经存在：系统 Now Playing 展示与独立扩展需分开验收。投屏图标也不证明同时支持 AirPlay、DLNA、电视扫码登录。

## 尚不能视作已核实 iOS 能力的项目

- 设备媒体库、全部本地格式、新拟态/粉粉磁带、EQ“仅本地”等来自用户补充清单，作为音枢需求保留；不等于已通过 Sollin IPA 实测。音枢的 EQ 已用于可处理的在线 PCM，不因该限制缩减。
- Emby、完整文件标签写回/跨库去重：官网总览混合平台，暂列参考候选；不能凭桌面说明认定移动 iOS 完整具备。SMB 未因 WebDAV 自动纳入。
- AirPlay/DLNA、电视扫码、独立小组件/Live Activities：图标与当前移动日志线索可调查，但协议和 iOS 可用性需分别核验；不把系统灵动岛直接当作扩展开发需求已验收。
- 桌面专属的混响/环绕、AB 循环、倍速、ReplayGain、智能歌单/评级不直接计入 iOS 对齐差距。用户若后续加入则另行扩展。
- 赞助/付费解锁、参考 App 账号后台、QQ 群等商业分发机制不复制为音枢依赖；音枢使用自己的名称、图标与资产，不打包他人界面中的唱片/人物图片。

## 范围变更与实施顺序

本次明确纳入：设备媒体库/本地文件曲库、WebDAV、多款主题与五播放器皮肤、完整个性化、睡眠定时器。用户“尽可能功能对齐”同时将 J08–11/J37–38/J47/J53–56 列入扩展目标，具体接口可用性与验收仍需探索，不声称已经落地。此前“不做本地文件管理”、评论和持续同步的排除不再代表最终总目标；CarPlay/ECARX/Android 正式版/SMB/正式商店发布仍未新增。

建议执行：
1. 收尾现有 LX/汽水匹配/迁移可靠性，固定回归证据；保留真机待验项。
2. 先建立主题/导航/mini/封面取色/统一曲目行，按九图改发现与歌单详情，再完成 AM、沉浸、写真、黑胶、声波核；不是只做静态页面。
3. 同步补逐字渲染、TTML、歌词设置、EQ 曲线/前级/自定义方案及睡眠定时器。
4. 扩展本地文件/设备媒体库、WebDAV、多实体搜索；再接入登录推荐/评论、云备份与统计等扩展。
5. 按用户已有安排最后交付永久离线下载与容量管理；每阶段本地/CI回归后提交 push，最后真机后台/性能/签名验收。

验收：同一固定样本在五个皮肤间切换不丢队列/进度、不重启音频；九页在浅/深色、大字和长标题下截图对照；歌词与频谱基于真实时轴/PCM；所有按钮实际接服务；账号/文件权限失败可恢复；成功打包不代替真机验收。
