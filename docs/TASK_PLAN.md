## 本次开始实施的边界

先提交可验证的基础：M0 工程与环境脚本、M1 模型/队列/竞态保护及真实测试，初始界面只提供已经接入的功能入口和准确的未配置状态。不能把未实现功能做成假按钮或随机数据。

框架候选：Expo 54 / React Native 0.81 新架构 / React 19.1 / TypeScript；npm 单锁文件；Node 24.14.0；CocoaPods 1.16.2；Xcode26.3。具体补丁版本以 package-lock.json 和构建记录为准。

原生管理决定：**维护并提交 ios/ 工程**。初建时仅生成一次 iOS 基线，后续 Swift/ObjC 模块直接受版本控制；禁止无记录 clean prebuild 覆盖。Pods/DerivedData不提交；不为首期生成Android工程。Expo插件配置与手动改动均写在构建文档。

播放器先通过 PlaybackBackend 接口隔离，待候选验证后固定一个后端；音源、元数据provider与Navidrome各自独立。首批不提前购买/复制 RNTP v5，不将许可未复核的参考代码导入。
