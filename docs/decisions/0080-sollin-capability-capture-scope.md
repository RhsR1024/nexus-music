# 0080：Sollin采集按功能能力收敛

日期：2026-10-24。状态：用户明确要求；适用于后续 Sollin Android 功能采集与功能清单整理。

## 决定

1. 采集目标是 Sollin 用户可见的功能与能力：入口、基本操作路径、结果状态，以及哪些能力未能确认。
2. 不为功能清单追加并发容量、速度、百分比、超时上限、极限值或内部实现等规格/性能验证。
3. 榜单名称和 ID 是目录数据，不按每个条目逐项打开。只验证目录可用、代表项能进入歌曲列表以及共享歌曲动作；参考项目接口用于音枢 provider 架构参考，不能作为 Sollin 内部调用证据。
4. 对未验证项区分条件未触发、需人工授权、需外设/第二设备和已观察但原因不明；不得推测为已支持或已成功。
5. 已有原始证据、历史规格与失败记录保留；不以本次范围调整自动提高完成度，也不擅自迁移或删除外置案例素材。

## 依据

用户明确说明本轮只需要知道 Sollin 有哪些功能能力（例如下载管理、单项取消、全部取消），不需要验证并发量等规格与性能；此前也明确榜单为固定平台接口提供的目录数据，无需逐个榜单打开。
