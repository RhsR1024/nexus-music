# 决策 0033：Sollin 移动端参考的移植范围

日期：2026-10-16。用户提供 `Sollin-2.0.0 60-unsigned.ipa` 后，明确要求以其移动端 UI、交互和设置组织作为参考，但不把 Sollin 自身的产品服务体系移植进音枢。

## 采纳范围

- 以移动端实际页面为行为参考，完整对齐可观察的布局层级、导航、弹窗、手势、状态反馈、错误恢复和设置组织；实现使用音枢现有 React Native/Swift/ObjC 架构，不能复制 Flutter AOT 二进制、私有服务、品牌图片、源码或第三方资产。
- 将以下四组设置作为完整对齐目标，并把其中与音枢范围相符的子项纳入测试矩阵：
  1. 播放与歌词：播放控制、音质、自动降级、队列/中断、歌词来源、偏移、字号/字重/颜色/对齐/行距/模糊、字体、逐字与 mini 歌词。
  2. 外观与界面：主题、明暗/系统、强调色、封面取色、背景、透明度/模糊/圆角、播放器皮肤、底栏与 mini 按钮、全局和歌词字体、横屏/iPad布局。
  3. 下载管理：下载音质、任务队列、暂停/继续/取消/重试、并发、命名、歌词/封面/元数据伴随下载、完整性校验、重启恢复、容量与在播保护；不复制参考 App 的赞助门槛。
  4. 数据与存储：本地音乐库、收藏/历史/歌单、临时缓存、永久下载、备份恢复、WebDAV、音枢多设备同步、迁移、数据目录和失败回滚。
- 保留音枢自身独有且不属于参考 App 的配置和能力，包括 LX 音源宿主与多源择源、Navidrome/Subsonic、音枢 WebDAV 账号边界、汽水公开歌单匹配、漫途一次迁移、来源诊断、真实 PCM/EQ、系统 Now Playing/灵动岛以及音枢的数据安全策略。

## 明确排除

- Sollin 自身的注册、登录、邮箱/密码、设备管理、用户中心、账号资料和其后台会话。
- Sollin 的赞助、付费解锁、订阅门槛、赞助专属功能开关和商业权益文案。音枢下载和其他目标能力按自身范围实现，不设置参考 App 的赞助限制。
- 免责声明、服务与支持、QQ群/GitHub支持入口、应用自推广和参考 App 的产品帮助体系。法律或隐私要求下音枢自己的必要文案另行维护，不作为 Sollin UI 复刻目标。
- 遥测、行为分析、诊断上传和任何未明确授权的用户数据回传；本地错误日志也不得包含凭据、私人曲目或完整 URL。
- Sollin 自有账号后台所依赖的 API、云端权益校验和服务端用户中心。参考包中出现的账号模块路径只作为排除证据，不作为实现任务。

## 音乐平台账号边界

网易云、QQ 音乐、酷狗等音乐平台自身账号登录保留为音枢 provider 能力。登录凭据只用于对应平台实际支持的能力，例如个人歌单、收藏、每日推荐、私人 FM、云盘或受权限保护的播放；每个平台单独记录能力和失败原因，不能把“已登录”写成“歌单同步已完成”。凭据使用 Keychain/平台安全存储，不进入音枢备份、同步文件、日志或诊断报告。

平台账号登录与音枢账号完全分离。音枢不新增自有账号体系；平台歌单/收藏的读取或回写按公开协议、用户权限和实际接口分别验收，不能从参考 App 的设置文字推断服务端一定支持双向同步。

## 验收与维护

先建立参考 App 的页面/操作→状态变化→错误恢复表，再以音枢自己的数据模型和唯一播放器实现。像素、动画和字体只有在实际运行截图/录屏与可访问性检查后才标记对齐；静态 IPA 字符串或二进制路径不算功能通过。四组设置的每个条目要区分代码、自动测试、模拟器、真实服务和真机证据。

本决策只改变参考移植范围，不删除 F01–F37/J01–J59 中用户已明确保留的音乐、播放器、下载、数据、平台账号和交付目标；未列入总范围的 Sollin 自有账号/商业/支持/遥测能力不计入进度分母。
