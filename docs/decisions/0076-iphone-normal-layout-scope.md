# 0076 iPhone 常态布局范围

- 日期：2026-10-21
- 状态：生效
- 来源：用户明确指令

## 决定

音枢当前只以 iPhone 常态字号、常态纵屏布局作为 UI 实现和截图对齐目标。

- 大字/辅助功能字号模式暂不实现，也不作为美观、间距或截图相似度验收目标。
- iPad 专用布局、分屏、窗口和旋转美化暂不实现，也不作为当前 UI 对齐目标。
- 普通 iPhone 的窄宽约束、安全区域、横屏可用性以及“不重叠、不裁切、核心控件可达”仍属于基础工程回归。
- 用户提供的参考图中出现的大字号歌词，是“歌词舞台”播放样式本身，不应解释为辅助功能大字验收。

## 对现有测试的处理

已有大字/绘图和 iPad 测试不删除、不改写历史证据；它们只证明兼容路径不会崩溃或阻塞核心操作，不再作为视觉完成度、剩余开发量或 90% 截图对齐的计分依据。后续不为这些模式新增专门美术收敛工作。

## 进度与验收

iPad 专用适配和辅助功能大字视觉优化从当前 UI 分母中暂缓，不从历史交付记录中删除。进度表在下一次正式重估时统一调整；本轮不因规则变化虚增已完成比例。
