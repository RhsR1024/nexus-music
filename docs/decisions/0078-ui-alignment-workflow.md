## 决定

采用 [UI_ALIGNMENT_WORKFLOW](../UI_ALIGNMENT_WORKFLOW.md) 为当前方法主规范：4855/4856样板→4854经典→平台功能纵向批次伴随UI→全量静态/动效收敛。样板优先修容器与状态，再修排版、字形/图标、材质和间距。用正式组件的测试场景缩短反馈，同时保留正常导航和阶段集成验证。

参考/场景/度量版本冻结，候选每轮更新并保存不可覆盖证据。全屏与关键区域、几何锚点、颜色/边缘、人工亲看和独立交互验收共同决定完成；禁止通过扩大遮罩、换主题或降低阈值达标。录屏缺失不等于交互一致，素材、原版环境或采集缺口同样不阻塞可独立完成的后端工作；阶段排序是主线优先级，对应UI集成验收仍保留。

90%最低目标、reverse-skill硬门禁、iPhone常态范围、音枢特有功能、许可/隐私、权威队列以及云端single队列规则不变。覆盖历史“全部UI精修结束后才新增功能”的串行安排；不新增/取消功能范围。
