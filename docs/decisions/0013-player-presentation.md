# 0013：五种移动播放布局

2026-10-15，S3 首批，对应 J26/J41/J48 部分；不是五皮肤、完整 AMLL 或原生累计扫色验收。

来源比较延续 0012 与 REFERENCE_COMPARISON：Sollin 移动九图提供构图，桌面 AmllFullPlayer/PlayerBackdrop 提供背景、歌词、控制分离的职责参考；其 AMLL React/DOM/canvas 不能直接嵌 RN。悦音 MiniPlayer 分离封面/歌词和进度；Q/wtf 校验实际逐字时间；Wayferar 的累计扫色仍是后续视觉验收要求；Cy 的新 RNTP/Expo 不为皮肤引入。此批原创 RN 组件，不复制图片/歌词/桌面 CSS 或库实现，不添加播放器/导航依赖。

## 行为与边界

- 新增 Preferences.playerLayout：classic/am/immersive/photo/vinyl/wave。旧记录缺值默认 classic，保留现有行为；设置和播放选项均可选，原子保存，坏值拒绝。
- ModernPlayer 只订阅现有 PlaybackController、PreferenceStore、LibraryStore；切换布局只更新外观，不调用 play/load/stop、不替换原始歌曲或队列。汽水仍用原曲身份收藏，歌词使用已确认匹配目标。
- AM：小封面头、大字左对齐有界歌词区域、大播放控制和进度；沉浸：大封面、曲目头、居中歌词及控制。当前背景为既有缓存封面原生模糊加暗渐变，缺图深蓝回退；不是新实现的色彩提取、流动背景或动态封面。
- 歌词只显示局部3–4行，沿用真实词时间与原生透明度动画；完整累计扫色、邻行实时模糊、字强调/弹簧滚动、TTML 与五皮肤仍按 S3/S4 继续。不声称已经复制 AMLL 动画。
- 进度按实际布局宽度计算，拖动只在释放提交 seek，取消不定位；手势期间 token 改变则丢弃旧拖动，避免切曲后误定位新曲；保留 VoiceOver 增减操作。音质徽章标为“档”，不把请求档位冒充实际媒体格式。
- 更多选项使用独立面板，复用现有来源诊断、真实频谱、收藏/加入歌单、汽水匹配、随机循环、完整队列和排序；不丢失旧功能。没有实现的下载/评论/投屏不放假按钮。

## 验证

旧设置迁移与校验、类型与全量业务回归；在合成 Navidrome 实际播放/暂停后切 AM→沉浸→经典，确认暂停意图/当前曲保留，截图检查布局；新选择写入同一持久化模型。播放器/手势仍需大字/小屏/长歌词及真机背景性能验收。云端先跟踪 2cb91a6 的 S1 原生材质/新依赖，不推新提交取消运行。

## 其余三种皮肤的基础实现

PlayerVisuals 为原创 RN 几何黑胶/唱针与32频带环形布局，无复制参考图片或纹理。黑胶以 Animated 原生驱动每圈22秒，不通过 React 每帧更新角度；暂停、缓冲、后台、系统减少动态效果均停止。旋转继续从当前值开始；未声称唱针具备完整机械仿真。声波核只订阅原有频带快照，32条长度来自实际FFT，暂停时回到基线，不制造随机频谱。

写真皮肤当前仅把歌曲缓存封面作为清晰背景，不等于已有独立歌手写真库/自定义照片导入，后续仍需图片来源与设置。AM/沉浸/写真/黑胶/声波核都复用ModernPlayer控制与歌词；媒体容器按屏幕高度缩放，确保主要播放控制可达。旧经典布局保留。布局枚举为 classic/am/immersive/photo/vinyl/wave。
