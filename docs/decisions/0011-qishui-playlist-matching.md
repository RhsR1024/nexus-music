# 汽水歌单与跨平台匹配

用户于2026-10-15明确加入首版。复核固定Wayferar PlaylistProviders（公开分页/原始身份）、PlaylistFallbackSearch（五平台分阶段搜索）与PlaylistFallback（宽松开关）。其宽松分支直接取首项，不适合在音枢不提示地替换歌曲。Q/wtf只提供五平台LX/元数据、悦音歌单交互与Cy抽象可参考；不搬入另一播放器或外部必需解析服务。Wayferar注明PlaylistOut MIT，若改编其代码需保留许可；本项目独立实现协议与匹配，不复制反编译代码。

原始汽水曲目使用独立imported/qishui身份，保留ID、标题、歌手、时长及歌单顺序/重复项。它不是LX播放平台，不伪造WY/TX ID。可播放目标仅允许五平台online Track，匹配记录单独保存于现有音乐库，备份保留原曲与目标。自动匹配要求规范化标题/歌手、版本标记相符且时长近似，缺信息或不确定时显示待确认；用户可明确选择候选/更换目标。

搜索按现有provider查询，无源/单平台故障不破坏原曲或其他平台候选。播放通过匹配目标走现有多源/音质路由，队列仍以原始条目为权威；缓存和解码重试键包含目标ID，避免不同目标污染。歌词可用匹配目标获取，原始封面有则保留。取消/切歌隔离仍适用，不加入汽水账号或直接音频播放。

公开歌单仅允许官方域名/可识别ID，逐页检查总数/游标；不完整返回拒绝落库。漫途备份的汽水条目复用同一身份和匹配，不跳过整首。TS匹配与数据模型可复用Android，原生文件/播放后端独立；须测试重复、长ID、错误版本歌曲、候选失败、人工确认、备份往返和取消，再进行真实公开服务与UI验收。
