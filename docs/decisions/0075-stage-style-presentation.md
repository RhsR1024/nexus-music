## 设计

舞台拥有固定窗口主体，歌词分配剩余高度；横屏常规字号采用歌词/控制双列，大字保留滚动阅读和独立主控。标题/更多入口、原曲收藏、实际录音歌词/字体、来源与全部歌词偏移入口、唯一权威队列和播放意图保留。普通歌词沿真实行级时间；没有词时间就不制造逐字时间。不同样式切换不改变播放位置。

新增四值stageStyle和独立stageBackdrop，默认霓虹/背景开；旧设置合并默认值，不动既有布局和歌词偏移。写入成功才发布新快照，失败留原设置；无效枚举/非布尔背景拒绝。选择Sheet明确经典/霓虹/赛博/炫彩选中态与独立开关，经典沿原背板，其他可关闭舞台背景。设置不是会员或服务授权入口。

原生TextKit绘制只接收可见当前组。经典保持原扫色；霓虹为青色光晕，赛博为双向青/洋红色差边，炫彩按组合字符分配稳定原创光谱并加柔光，真实词范围和时间不变。减少透明度时关闭额外光晕/色差，减少动态效果和后台等沿原有时钟守卫；没有新逐帧React状态、全列表动画或PCM传递。独立背景是原创静态渐变，不声称已恢复参考流光/粒子。普通未同步舞台歌词改为有界虚拟列表。完整入退场、碎片与可动背景仍待。
