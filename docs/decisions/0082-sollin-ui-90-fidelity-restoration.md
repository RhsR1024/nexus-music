# 0082：恢复 Sollin 前端 UI ≥90% 高保真对齐与全量功能完成目标

日期：2026-11-25。状态：生效；依据用户最新明确指令覆盖 [决策0079](0079-functional-spec-and-ui-quality.md) 中“取消全局 90% UI 对齐门槛”的临时放宽。

## 决定

1. **全量功能与前端 UI 双轨收口**：持续推进直到完成所有当前环境下可落地的任务功能（F01–F37 / J01–J59，排除项如识曲、漫途双向同步、Sollin 自有账号/赞助/遥测不变），并将全站前端 UI 全面对齐 Sollin 参考视觉。
2. **UI ≥90% 高保真目标**：以本机冻结的 Sollin 参考截图（`resource/reference-ui/sollin-2026-10-18/IMG_4851..4891.PNG` 与 `resources/sollin-reference/screenshots/01..39`）及已审查的 `reverse-skill` 静态证据为基准，力争各核心页面与播放皮肤达到 ≥90% 视觉复刻；对于因客观限制无法达到 90% 的页面或指标（例如不同照片封面纹理上限、音枢特有能力扩展区、无商业赞助墙、iOS 与 Android 平台路径差异、缺少参考真机录屏等），必须按页面逐项给出明确理由与度量证据。
3. **保留全部工程与合规底线**：保留 iPhone 常态布局主范围（0076）、`reverse-skill` 离线门禁、唯一权威队列、PCM/歌词原生渲染边界、音枢特有能力（LX 多源择源、五平台、Navidrome/WebDAV、汽水/漫途迁移、诊断、本地下载与备份同步）及凭据/隐私/许可边界；不为凑相似度删除音枢功能或伪造假入口。
4. **分波次验证**：每批完成类型/单测（`npm run check`）、原生测试（`npm run test:native`）、真机模拟器截图与 `visual-lab` 量化/人工亲看验证，确保不破坏已有回归用例。
