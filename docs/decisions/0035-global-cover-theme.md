# 0035 封面驱动软件全局背景

2026-10-17，A04/A05、F25/J45–50。用户要求先从IPA逆向调查、再用截图补充，并优先补齐已有功能。

## 证据和实现边界

固定Sollin IPA/hash沿[SOLLIN_IPA_ANALYSIS](../SOLLIN_IPA_ANALYSIS.md)。直接静态证据为“使用封面主体色，应用到全局及原始、经典播放器”“背景随封面变化”“从封面取色，保持静止”，以及resolve/load/applyCoverTheme、effectiveAppTheme、ThemedPageScaffold与背景配置字段。它们证明全局作用范围是合理对齐目标；当前尚未恢复函数调用和具体取色算法，不把不同播放器的palette/HSV符号拼成同一管线。

五参考比较延续已亲读的[0028](0028-visual-assets-and-player-backgrounds.md)：悦音配置职责、Q主题背景字段、wtf图片/子内容分层、Cy有界缓存/过期守卫/亮度约束、自有Wayferar明暗可读性。来源、固定提交、许可和Android边界不变。本批原创扩展现有服务，不复制Sollin AOT、shader、图片、依赖或其他参考取色代码。

## 状态和行为

- CoverThemeStore观察权威队列当前条目与实际resolved matchedTrack。背景不使用尚未生效的已存人工匹配替换当前录音。封面身份包含来源、封面地址、DAV版本、设备签名；账号/音源/缓存变化可主动失效。
- 每次身份变化立即回退既有主题并取消旧请求；封面加载、原生取色两次异步之后都核对取消标记。无图、下载/解码/取色失败使用固定主题，不将私有错误文本显示出来。图片显示失败只去掉模糊图层，保留已验证的色彩，不反复请求坏图。
- 复用CoverService受限加载与VisualColorCache的50项缓存/32项并发上限，原生ImageIO最长32像素采样。清缓存使旧请求失效，旧finally不能删除同URI新请求。TS只发布封面/色彩变化，播放position和PCM不驱动全局React渲染，也不写播放意图/队列。
- 当前阶段为**静态主体色渐变+低不透明度模糊封面**，用于发现/音乐库/设置/mini周围和经典播放页。明暗两套有界色彩映射与语义文字保持可读；开启后覆盖自选全局背景，关闭恢复原设置，不删除用户图片。现代播放器继续原有写真/封面/纯色选择，并改用实际播放录音封面。
- 这不是已还原的Sollin取色、流动shader或视频封面算法。全局层不播放动画；播放页既有运动、减少动态效果/后台暂停逻辑保留。更精确渐变比例、流动效果、低电量/手机功耗及参考App动态观察仍需后续验收，不勾整项完全等价。

## 验证门槛

业务检查覆盖快速A→B/迟到下载及取色、实际匹配录音、同曲版本变化、开关/清队列/坏图/失效、进度和暂停不重复取色；红蓝及极端黑白封面下的语义文字对比度包含模糊图层最坏像素。App必须通过合成红蓝封面真实Navidrome加载、跨发现/音乐库/设置、关闭恢复及重启暂停；再记录本地IPA和对应云端。原生算法已在0028契约中覆盖，未修改其实现。本批结果见BUILD_STATUS；手机和真实封面观察单列。

TS协调/颜色映射可共享Android，原生图片限制/解码/取色需对应Android服务；本批无新产品依赖。
