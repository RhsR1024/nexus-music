# 0024 跨平台歌词候选与独立选择

2026-10-16；F27/J38，延续0015，不改变播放路由。

固定参考及许可见REFERENCE_COMPARISON。Q-1515 `src/core/music/utils.ts:415–463` 和wtf同文件415–459按候选逐个取带时间标签的歌词；Q当前在线主流程466–504直接失败而非调用跨源，不能仅看辅助函数宣称全流程已接入。Cy `src/components/lyric/index.tsx` 与 `src/helpers/userApi/xiaoqiu.js:128` 分离显示和歌词搜索；悦音 `src/core/lyric/parser.ts` 提供行级/翻译，不可由行级模型伪造逐字。Sollin `src/services/officialLyricApi.ts` 保留多平台独立协议和富时间，但DOM/Buffer/解压后端不可整体搬入RN。Wayferar依据WAYFARER_LYRICS_REFERENCE保留真实时间与累计绘制，两条原生渲染职责不合并成每帧React全列表。均只参考问题/契约，不复制代码或引入第三方服务、依赖、字体；原有各自MIT/Apache/自有资产边界不变。

原创实现独立歌词选择层，复用现有五平台搜索、严格版本/歌手/时长匹配与歌词解析。默认保留当前实际录音版本的原歌词；可对公开曲目显式开启自动优选，只有可靠且时间轴不越界的候选才可自动采用，逐字/覆盖率/翻译用于有界排序。保留原歌词入口及来源标签，候选失败不破坏已取得的原歌词。人工候选支持关键词/分页、获取预览再保存，不以首个搜索结果自动替换。歌词改变不调用播放器/解析音频/修改队列，单曲偏移继续对实际录音版本生效。

Navidrome/文件/设备/WebDAV曲目默认只读取自身歌词，不自动向在线平台发送私有元数据；用户主动进入公开歌词搜索并确认后，才发送歌名/歌手。私人曲目不支持自动优选。选择按实际录音的来源/标题/歌手/时长签名保存，录音变化后旧绑定不套用；修改/关闭/切曲废弃迟到结果。SQLite/备份保存选择与清洁歌曲信息，排除鉴权URL/凭据/容器路径，保持旧备份兼容。

TS搜索/评分/仓储可供Android共享，现有原生累计歌词绘制仍需Android对应实现。验证覆盖可靠/现场版/未知时长、坏歌词/越界、取消/旧结果、手动失败回退、来源与备份隔离、失败写入和重启；随后本地App实际播放中切换歌词及双构建。实现不等于真实全部曲库/手机验收。

自动优选按五个平台分别保留一个最靠前的可靠候选，避免同平台重复项耗尽名额；两并发、25秒总预算，超时只使用已取得的有效结果并明确报告不完整。同分保留原歌词，其余同分按候选顺序稳定选择，不由网络先后决定。未知时长、不同现场/翻唱版本或超出录音时间轴的歌词不能自动替换；人工仍可预览后指定。重启队列先恢复暂停，待用户继续播放确认实际录音后再应用该录音对应的绑定。

录音签名同时包含WebDAV的davVersion和设备媒体库deviceSignature；同名同长但文件版本变化时，人工选择与原歌词缓存都失效。无可靠版本的WebDAV临时版本加入本进程实例随机命名空间，避免计数器从1重新开始而复用旧绑定；这只是失效标识，不作为音频完整性或认证证明。
