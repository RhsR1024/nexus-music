# 0079：功能规格优先与 UI 质量验收

日期：2026-10-23。状态：用户明确认可四点调整，覆盖0078及更早文档中冲突的90%硬门槛与样板前置顺序。

## 决定

1. 功能按明确清单和状态路径严格验收，重点覆盖播放、权威队列、导入、持久化、取消与异常恢复。功能以Sollin实测为参考，与音枢既有范围取并集；既有排除项及许可、隐私边界不变。
2. UI按体验与质量验收：层级清楚、风格统一、无裁切遮挡、控件可达、反馈明确、操作顺畅；允许布局、图标和材质差异。取消全局90%相似度硬门槛，不替换为另一个百分比。
3. 播放器、歌词、主题等重点页面单独确定精修目标；未逐页确认像素目标前，不自动延用全局逐像素要求。
4. 全局像素相似度和历史样板静态达标不再阻塞功能纵向批次。SSIM、色差、锚点工具保留用于诊断和明确选定的精修任务。

## 采集与开发

先建立实机功能规格：入口、前置条件、步骤、状态变化、返回/重启语义、标注截图、必要录屏、平台/版本及证据状态；按功能纵向批次采集并实施，避免先穷举全App才开发。

Android先验证连接并试采播放器、队列、歌词、设置；iPhone条件具备后核验iOS差异。Android观察不能直接作为iOS一致性的证明。界面显示、实际播放、后台/系统控制分别验收。未知项写待验证，不能推测为已实现。

继续使用reverse-skill路由、PRIMARY、工具索引、scope/case-guard与Evidence→Finding→Path。已有离线案例不得重初始化；设备观察另建范围，USB设备识别不等于动态功能已采集。只观察用户授权的设备与Sollin界面；不据此扩展私有服务探测、商业逻辑移植、凭据提取或全局客户端配置。

## 验收与迁移

每个功能分别记录代码、业务测试、正常导航、UI质量、真实服务/真机结果。动效可按自主设计验流畅性；只有宣称与Sollin一致时，才要求参考与候选录屏证据。iPhone常态布局范围仍有效。

历史基线、失败与静态2/5等结果原样保留，标为旧口径；不能自动转换为新标准通过量。新清单需按功能状态重新验收，本次规范调整不增加完成度。
