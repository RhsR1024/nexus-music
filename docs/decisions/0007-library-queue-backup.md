# 音乐库、队列恢复与备份

F07/F11/F19。悦音core/config/playlist.ts使用AsyncStorage并归一化简化Track；Cy有持久化/播放状态边界；Q/wtf的完整MusicInfo与Wayferar备份强调平台ID/元数据/重复曲序。采用原创SQLite仓储+领域模型，不搬入另一套状态管理、不丢失LX meta，不将车机Android路径/账号配置放入音乐库。

收藏按完整来源身份去重；歌单每次添加创建独立条目ID，重复歌曲及顺序保留；历史只由原生实际播放进度事件触发，最多300条。导入先完整验证后单事务写入，失败旧库不变。音枢备份使用format/version字段，不包含源脚本、账号密码或音频文件；未知版本拒绝。漫途迁移仍在M10，不能混同已实现的音枢备份。

一个权威队列，分别保存队列结构和进度游标；队列变化原子保存结构+游标，播放中进度最多每5秒写一次，暂停立即写入。重启恢复为暂停，首次用户播放时原生定位后发声；不存在自动启动播放。旧媒体/错误回调仍以generation和entryId过滤；解码失败跨源回退保留已播放位置。

共享TS模型和SQLite接口方便未来Android；真实锁屏/进程终止/覆盖升级、存储失败恢复另验。当前合成样本与SQLite测试不替代实际用户歌单迁移和真机续签验证。
