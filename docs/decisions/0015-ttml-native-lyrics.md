# 0015：TTML 子集与原生逐字绘制

2026-10-15，S4 / J35–42。比较固定提交见 REFERENCE_COMPARISON / 0008：Q/wtf 保留真实字时间；悦音/Cy 行级模型不能补造逐字；Wayferar 的自绘累计扫色与当前字强调是行为参考；Sollin 桌面 ttmlLyrics.ts:113–164 的声部/词分离可参考，但 DOMParser 与 TtmlLyricPlayer 的全列表 30Hz setState 不移植。全部新实现为原创，未复制其解析器、字体、图片或动画代码。

解析遵循 [W3C TTML2 时间容器](https://www.w3.org/TR/ttml2/#timing-attribute-timeContainer) 的并行容器相对时间，保留 agent/x-bg/翻译/罗马音，支持秒/毫秒/分/时/帧/tick 和时钟格式。这是明确的歌词子集，不宣称完整 TTML2：外部资源、DTD/实体展开和样式布局不支持；坏 XML/越界/深度32/2MiB/有界节点直接拒绝。不能照抄桌面将所有嵌套 begin 当绝对时间的逻辑。没有联网 TTML 库或自动跨平台匹配服务的可用性证明，先接已有歌词返回/导入的文本归一化。

2026-11-02 扩大有界时间子集：`timeContainer="seq"` 按 [SMIL 3.0 顺序容器](https://www.w3.org/TR/2008/REC-SMIL3-20081201/smil-timing.html#Timing-SeqSyntax) 处理。首个子元素相对容器开始，后续子元素默认相对前一个活动结束；子元素的 `begin`、`end` 和显式 `dur` 使用同一顺序同步基准，父容器边界仍会夹紧有效区间。未写 `timeContainer` 的元素保持 `par`；`par` 与 `seq` 可嵌套，显式时间和由子元素推导的隐式结束都沿用现有天数上限、深度32和全局歌词词数预算。顺序容器中的纯文本匿名跨度按规范为零时长，显式定时的 span/par/seq 保持可读文本、逐字时间、agent、背景声、翻译和罗马音。`excl` 等未实现容器、负时间和起止倒置仍拒绝。

2026-11-02 增加显式 AMLL 时间配置：仅当根 TTML 元素声明命名空间值 `http://www.example.com/ns/amll` 时，`begin`/`end` 按媒体绝对毫秒解析，接受库中使用的 `1.456`、`00:13.120`、`1:02.123` 和 `10s` 等缩短时钟。普通 TTML 继续使用父容器相对时间；未混入该名称空间的同名前缀不被识别。AMLL 配置明确拒绝 `timeContainer="seq"`，避免两种时基混用。`x-bg` 可独立于主 `<p>` 时间存在但仍受最近区段/歌曲边界夹紧，背景翻译/罗马音保留在背景行；合法零时长空白跨度只连接相邻词。ruby 注音布局暂时明确拒绝，由归一化改选 LRC 或其他歌词，不能把注音复制成演唱词。固定提交 `b411e06e` 的 12 个真实库抽样中 11 个成功、416 行/3,749 词与独立 oracle 一致，1 个 ruby 样本按预期拒绝；这证明的是有界解析配置，不是完整 TTML2、真实歌曲 App 音轨、实体机或签名验收。

原生绘制按真实词时间进行累计裁切，当前字轻微发光；布局和计时与 React 隔离。仅当前有界行可启动刷新，暂停/移出窗口/后台/减少动态效果停止，React 不逐帧更新整份列表。字体文件只读 App 导入沙箱，缺字体降级系统，不复制参考字体。单曲偏移、候选选择和更多样式仍分别验收，不能用解析通过冒充全部 S4 完成。

本批补充：单曲独立偏移最多5000条、±10分钟有界，零值移除；与全局相加，100/500ms精调/重置，写失败保留原值。双击同一首/同一行350ms内定位，VoiceOver激活直接定位；长按打开全部歌词/偏移，选择跟随皮肤/左/中对齐。实际合成字时间在暂停时定位截图确认部分累计填色，不代表真实TTML库/全部字体/手机渲染性能已完成。更多颜色/行距/模糊、跨平台歌词候选仍在S4。
