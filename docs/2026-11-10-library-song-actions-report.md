# 音乐库单曲菜单与批量下一首、下载

音乐库首页和完整歌曲列表现复用正式歌曲菜单，可从原条目分享、选择下载音质、查看相似歌曲和评论，并保留歌单上移、精确移除与历史删除。完整列表新增批量下一首和下载；批量动作按当前排序提交，搜索不丢弃已选但暂不可见的条目。

## 行为与边界

| 场景 | 现在的行为 |
| --- | --- |
| 音乐库单曲更多 | 共用 `TrackActions`，分享与下载使用原歌曲身份；歌单管理使用准确 `entryId`，上移执行前重读真实位置 |
| 音乐库收藏 | 明确使用音乐库集合；本地音频的单曲收藏标志仍由其原有入口管理 |
| 批量下一首 | 将已选歌曲按当前排序一次插到当前曲后，保留原队尾、重复条目和当前播放意图 |
| 批量下载 | 使用既有下载提交服务，逐条区分受理、已有与失败；全部受理后清除选择，失败时保留选择 |
| 下载结果返回 | 全屏结果预留实际顶部和底部安全区，返回按钮不再与状态栏重叠 |
| 关闭并重开同一歌曲菜单 | 每次菜单会话独立；旧收藏、下载或管理操作的异步完成不能关闭或修改新会话 |

这些改动组合既有业务服务，没有新增第二套队列、播放意图或下载存储。五参考的来源、固定版本、许可及架构取舍沿[参考比较](REFERENCE_COMPARISON.md)和[共享歌曲动作](implementation-shared-song-actions-2026-10-24.md)，没有复制参考资产或依赖。
