## 有意义的验证

业务单元/契约测试优先覆盖：

- 来源稳定ID、长数字ID、曲序/重复项、导入版本与原子写入。
- 队列FIFO/删除当前项/随机边界/暂停后迟到结果/取消和过期回调。
- provider字段缺失、分页完整性、音质有限降级与失败保留旧内容。
- 歌词坏时间/逐字降级/偏移，缓存跨账户/平台/音质隔离。

真机验收覆盖：后台下一首、锁屏/耳机控制、来电/路由变化、定位与歌词同步、弱网与源失败、覆盖安装/续签。模拟器、静态检查、JS测试、成功打包均不能替代这些。

文档改动不安装整套应用依赖，只校验内部链接、证据引用和范围一致性。构建失败先记录具体版本与错误，避免重复无意义地全量重试。
