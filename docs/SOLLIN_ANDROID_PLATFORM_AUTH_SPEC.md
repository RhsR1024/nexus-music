## 网易云手机号路径

1. 发现→账号与发现设置→音乐平台账号→网易云音乐账号。
2. 点击手机号登录，打开官方内容的WebView外壳；应用顶栏提供返回、完成登录及刷新图标。
3. 页面展示手机号登录、协议勾选及QQ/微博图标。图标可见不等于其授权成功。
4. 未勾协议时点击手机号登录，弹出服务协议/隐私指引，提供不同意和同意并继续。
5. 点击不同意后弹窗消失，仍停留官方入口。未发送短信、填写号码或同意新协议。

E-1150/E-1152/E-1154提供上述状态。尚未验证页面加载失败、WebView回退栈、短信错误、风控挑战与成功回传。

## 扫码路径的采集方法与边界

从网易云账号页打开扫码登录后，界面提供等待扫码、刷新二维码、复制链接。普通UI文字提示使用网易云App扫描生成二维码的链接，且说明扫码成功未自动登录时可能需要手动补充登录信息。该提示只证明页面说明，不能当实际扫码失败/成功证据。

二维码和链接包含临时授权材料，不纳入仓库或原始交付。等待/过期采样只保留明确允许的状态标签和采样时间，不记录二维码像素、payload、Cookie或手机号。等待超过一段时间仍无变化只能写“该观察窗口保持等待”，不能写“永不过期”。刷新入口点击后还要验证返回等待；不复制链接、不扫描确认、不覆盖原会话。

## 数据处理与实现建议

已有会话字段会在账号表单显示；禁止直接全量打印/保存账号控件树。先在内存剔除EditText内容、身份和session类字段再保存脱敏结构。q187敏感原截图/XML已移除，有回执和脱敏替代；不能继续把原图列为可取附件。

音枢建议区分：账号摘要、授权尝试、待人工确认、成功待保存、保存完成、取消、过期和失败。此为实现建议，尚未通过全部Sollin动态证据证明同一内部状态机。已有账号展示与新授权是独立验收；provider会话不能与Sollin自有账号混用。
