## 已发现的问题与处置

1. 动作日志第1095条的q94图片哈希与当前文件不一致。E-990中的哈希与当前文件一致。保留原日志sha256，增加审查状态、当前校验值和来源 caveat；未把重算值冒充原始采集值。该图片不能作为无争议的原始完整性证明，收藏歌单多选应补采或在使用时保留限制。
2. 平台筛选证据只展示歌曲行结构，不能证明每个平台的后续多选/收藏/下载均成功。外部报告已收紧对应表述。
3. mini显示暂停只能证明界面播放状态变化，不能单凭截图证明可听音频输出。全局搜索本批普通点击证据按此等级使用。
4. 非语义数字查询返回近似结果，属于观测行为；“模糊匹配算法”“规范化实现”只能作为解释候选，未分析服务端算法。真正无结果态仍缺稳定样本。
5. 艺术家搜索和详情专辑计数不一致。实现规格分别记录摘要与详情计数，避免强制复用同一总数。
6. 历史段落含已经被后续证据补齐的“仍待”描述。历史时间线保留，当前状态须以最新功能矩阵为准；尚需逐章去除把历史残余当作当前残余的歧义。
