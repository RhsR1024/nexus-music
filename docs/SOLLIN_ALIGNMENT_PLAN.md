# Sollin IPA 优先对齐任务清单

更新：2026-10-17，Asia/Shanghai。本文是用户最新要求的执行清单，优先于旧M/S批次的开发顺序；总范围F01–F37/J01–J59保留。

## 最新明确要求

1. **证据顺序固定为IPA逆向信息优先，截图补充。** 先从固定Sollin iOS 2.0.0 build60包中核对类/方法、对象池、配置、页面层级、选择器、歌词/播放器与背景机制；再用补充截图和早期九图补齐视觉。不能先按截图假定交互，再以同名字符串当调用证明。
2. **先对齐已有功能，再实现其他功能。** 以完整复刻已有UI和交互为目标；先落实入口、层级、控件、选择/取消、返回、菜单/手势、错误状态、持久化和音乐核心操作，再扩展尚未实现的能力。不用“类似皮肤”或静图代替完整对齐验收。
3. 保留音枢已有特有能力：LX独立宿主、多源优先级与同档跨源后降档、五平台、Navidrome/Subsonic、WebDAV、汽水原始身份与匹配、漫途一次迁移、来源诊断、真实PCM/EQ、权威队列/播放意图、原子存储和凭据保护。UI可重组，底层规则不能被参考App覆盖。
4. 补充截图已复制至`resources/sollin-reference/screenshots/`并按内容命名；原QQ目录保持不变。最初69张PNG，剔除1张非Sollin的Apple ID/签名验证画面，最终**68张、35组画面**，保留QQ变体、不改图像字节。索引`resources/sollin-reference/INDEX.md`与`screenshot-manifest.json`仅本机保存，整目录忽略Git且不作为产品资产。发现其他非Sollin画面继续剔除，不把个人凭据/验证码带入资源或证据文档。
5. **封面驱动软件背景是优先移植项。** 核验并实现当前歌曲封面→取色/模糊或图像流动→软件全局背景/适用播放页；切换不同歌曲时背景随之变化。先从IPA追踪实际实现和配置，不能把“已有播放页模糊图片”或“固定主题渐变”当作已完成。静态取色/模糊与动态背景、动态视频封面分别验收。
6. Sollin自有账号/用户中心、商业门槛、支持推广和遥测仍排除；音乐平台自身账号能力保留在provider范围。阶段验证后提交并正常push，继续跟进排队构建和失败。不得以本机SDK26.2、模拟器或unsigned包冒充本机iOS27/真机/签名通过。

## 背景专项验收细化

- 明确区分“封面主体色影响软件全局背景”“模糊封面图层”“流动背景动画”“动态视频封面”，不把一个开关的实现替代四种效果。
- 原始曲与实际匹配录音分开；背景沿实际播放录音封面，同一权威媒体身份。A→B快速切歌、封面慢请求、匹配版本变化、账号/文件版本变化都不能出现旧图覆盖新曲。
- 原生/有界低频取色与缓存，布局层只接必要颜色/资源变化；不把PCM逐帧传React，也不为背景重建音频。后台、减少动态效果、低电量策略分别核验。
- 同时检查发现、音乐库、设置、mini与适用播放页；白/黑/透明/损坏/无封面和大字时文字、图标、控件可读可达。图片缓存与个人凭据隔离。
- 本地合成红/蓝等可辨封面提供确定性切歌证据，之后真实封面和手机观察；模拟器颜色变化不代表原始算法或真机功耗已完全等价。
