## 实现

- 详情长按进入选择，逐行切换、全选/取消全选/退出；显示原生圆环与勾选标记，行无障碍状态与提示同步。选择时隐藏逐行动作和名称编辑，保存过程中禁止切换歌单。
- 收藏使用本地音频身份，而非歌单条目ID；只写设备单曲标志。已物理移除的音频记录使整批收藏失败，原状态保留；索引隐藏但仍持有的音频可以继续编辑。
- 加歌单继续走设备域选择器，提交后关闭选择面板；下一首按列表顺序进入同一权威队列，按歌曲身份去重，重复提交明确反馈。
- 批量移出以歌单条目ID一次持久化；同一歌曲的其他条目、索引、音频副本和队列不被删除。写盘失败不发布部分状态，失败后的排队编辑可恢复。
- 人工检查发现旧浅色队列将深色界面前景常量放在浅背景上，现于QueuePanel/QueueRow边界使用语义颜色；AM嵌入深色语气独立保留。无新依赖、provider接口或参考代码采纳。
