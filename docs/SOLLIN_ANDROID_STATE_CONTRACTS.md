# Sollin Android 状态与交互契约

本表用于把已采集行为转成实现任务。参考版本为Android 2.0.0；是Android观测规格，不自动成为iPhone视觉验收标准。Evidence位于T7案例。状态名称是文档建模名称，未声称还原Sollin内部类名或算法。

## 全局搜索与详情

| 前置状态 | 动作 | 后置状态/可见结果 | 证据与边界 |
|---|---|---|---|
| 发现普通页 | 搜索入口 | 搜索类型、平台、历史/热词与输入框 | E-303、E-1010；历史清除持久化仍需复核 |

| 歌曲结果 | 长按/全选 | 1/20→20/20、批量动作面板 | E-1012/E-1014；未执行批量副作用 |

| 每日推荐/其内部搜索 | 未进入多选；搜索长按普通选曲 | 普通歌曲路径 | E-976/E-1002/E-1004；不能强行统一为所有页面相同 |

所有选择状态实现任务应显式区分 `loadedItems`、`selectedIds`、`totalCount`。这是音枢建议的数据模型，不是反编译结论。专辑前两首批量“下一首”已验证：当前Love保持，队列100→102，两首按专辑顺序插入当前之后，面板关闭；删除插入项恢复100（E-1082–E-1090）。这一结果仅覆盖该专辑、该选择顺序和无活动音频条件，不代表其他批量副作用。

批量动作至少需要等待、逐项成功/失败、重试、取消与重复提交策略；这些策略仍需由后续证据或音枢产品决策确定，不能伪称Sollin已验证。

## 生命周期与持久化

| 前置/动作 | 已观测结果 | 证据与限制 |
|---|---|---|
| Home后返回 | 保留页面/媒体会话；定时倒计时继续 | E-318/E-950；与强制停止区别对待 |
| force-stop后启动 | 发现首页，media-session无活动 | E-638；不意味着所有偏好丢失 |
| 设备重启后启动 | 发现首页，无活动播放；随机开关仍保持 | E-642/E-946 |
| 运行定时器后force-stop/设备重启 | 定时器运行态不恢复 | E-928/E-930/E-952 |
| 短定时器自然到期 | 媒体会话暂停，面板关闭 | E-958；不能外推所有系统后台时序 |
| 自建歌单保存后重启 | 本设备歌单保留，可删除 | E-852/E-854/E-856；非跨设备写入证明 |
| 随机开关、排序方向后重启 | 本轮偏好保持 | E-932/E-934/E-936/E-942/E-944 |

## 关键异常与实现边界

| 功能 | 观测结果 | 实现/补证要求 |
|---|---|---|
| 系统媒体输出 | 系统dialog不可用 | 记录失败与返回路径，不宣称投放成功（E-616） |
| 无效歌单URL | 等待约30秒无可见错误，取消无新增 | 音枢需决策超时反馈；不能复刻静默卡住（E-866/E-868） |
| 下载断网 | 0%失败、原因、重试/移除记录；网络恢复记录保留 | E-840/E-842；重试成功、活跃暂停/恢复/断点续传仍待 |
| 扫描过滤 | 时长/屏蔽路径保存，但样本仍全部出现 | E-844–E-848/E-938/E-940；保存与生效是不同验收项 |
| 队列锁定 | 当前页编辑隐藏，外部选曲仍重建队列 | E-918–E-922/E-964–E-968；不得写成禁止全部外部替换 |
| 播完当前曲再停 | 本地三模式、在线默认/随机/单曲观察到继续 | E-962/E-970/E-974/E-986/E-988/E-1006/E-1008；记录参考异常，音枢应明确预期优先级 |
| 实时同步 | 开启时已删歌单重启回灌，关闭后不回灌 | E-908–E-914；跨设备删除传播与冲突未验证 |

当前表不代表所有状态均完成采集。后续增加证据时更新对应行，同时清理摘要中过期的未验证描述；不要只累加时间线而不更新当前契约。
