本表用于把已采集行为转成实现任务。参考版本为Android 2.0.0；是Android观测规格，不自动成为iPhone视觉验收标准。Evidence位于T7案例。状态名称是文档建模名称，未声称还原Sollin内部类名或算法。

所有选择状态实现任务应显式区分 `loadedItems`、`selectedIds`、`totalCount`。这是音枢建议的数据模型，不是反编译结论。专辑前两首批量“下一首”已验证：当前Love保持，队列100→102，两首按专辑顺序插入当前之后，面板关闭；删除插入项恢复100（E-1082–E-1090）。这一结果仅覆盖该专辑、该选择顺序和无活动音频条件，不代表其他批量副作用。

批量动作至少需要等待、逐项成功/失败、重试、取消与重复提交策略；这些策略仍需由后续证据或音枢产品决策确定，不能伪称Sollin已验证。

## 关键异常与实现边界

| 功能 | 观测结果 | 实现/补证要求 |
|---|---|---|
| 系统媒体输出 | 系统dialog不可用 | 记录失败与返回路径，不宣称投放成功（E-616） |
| 无效歌单URL | 等待约30秒无可见错误，取消无新增 | 音枢需决策超时反馈；不能复刻静默卡住（E-866/E-868） |
| 下载断网 | 0%失败、原因、重试/移除记录；网络恢复记录保留 | E-840/E-842；重试成功、活跃暂停/恢复/断点续传仍待 |
| 扫描过滤 | 时长/屏蔽路径保存，但样本仍全部出现 | E-844–E-848/E-938/E-940；保存与生效是不同验收项 |
| 队列锁定 | 当前页编辑隐藏，外部选曲仍重建队列 | E-918–E-922/E-964–E-968；不得写成禁止全部外部替换 |
| 播完当前曲再停 | 本地三模式、在线默认/随机/单曲观察到继续 | E-962/E-970/E-974/E-986/E-988/E-1006/E-1008；记录参考异常，音枢应明确预期优先级 |
| 实时同步 | 开启时已删歌单重启回灌，关闭后不回灌 | E-908–E-914；跨设备删除传播与冲突未验证 |

当前表不代表所有状态均完成采集。后续增加证据时更新对应行，同时清理摘要中过期的未验证描述；不要只累加时间线而不更新当前契约。

## 批量下一首的顺序与重复提交

E-1092–E-1104补充：专辑第二首先长按、第一首后勾选，插入顺序仍为第一首→第二首。两首已紧邻当前时，重复选中2/14提交，选择面板关闭，队列保持102而非104；删除两项后恢复100。本次只证明这个相邻重复场景没有新增，不能声称全队列去重、跨平台同名合并或并发提交安全。

验收时分别断言当前曲保持、页面选择退出、总数、紧随当前的两项顺序和原后继；不要只看成功提示或总数就判定顺序正确。参考版本的异常行为（睡眠开关未停、扫描未过滤、无效链接静默等待）与音枢期望行为应分别决策，不能把已观察异常自动升级为必须复制的需求。
## Q89 本设备批量收藏闭环

音乐库收藏0→专辑选择2/14收藏→选择面板关闭→强停重启音乐库2首→收藏列表全选2/2取消收藏→提示已取消2首并回0→重启仍0（E-1106–E-1118）。证明本设备收藏和批量取消的持久化，不证明provider远端写入、混合收藏或重复请求。下一轮按采集交接补批量加歌单。

## Q90 本地歌单批量写入

空容器→专辑选择2/14→批量选择器显示已选2首→选择容器→选择器关闭但2/14面板保留→重启容器2首且标题一致→编辑删除确认→重启我的歌单0（E-1120–E-1146）。显示顺序受添加时间排序影响，未证明插入/存储算法。音乐平台授权完整状态机仍缺，不能由已有登录态推荐入口推断授权通过。

## Q91 平台授权入口

网易云账号→手机号官方WebView→不勾协议点击登录→协议确认→不同意→回登录页（E-1148–E-1154）；QQ账号→网页登录→音乐网站桌面首页加载（E-1156/E-1158）；酷狗账号含短信验证码和手动信息入口（E-1160）。三个账号已有状态，未退出或发短信，不能计新登录成功。手动字段仅记录形态，不保存已有会话内容。

Q94收藏歌单多选独立复核：等待28首加载→首行长按1/28→全选28/28→取消普通列表（E-1170/E-1172/E-1174）。该链可独立支持当前状态契约，旧q94原始哈希差异保留审查记录。

## Q95 本地批量移除：取消、确认、持久化与重扫

两首隔离 WAV 扫描后：长按单首 1/2 → 全选 2/2 → 取消，列表保持 2 首。再次进入选择后确认对话框标题为“从本地列表移除？”，正文为“将移除 N 首歌曲，不会删除设备上的原文件。”，N 随选择数在 1/2 间变化（E-1176–E-1190）。确认后列表归零（E-1180/E-1192/E-1194），两首 WAV 的哈希日志仍可在设备上取到，证明是索引移除而非文件删除（E-1182）。

移除后 force-stop/重启仍为 0（E-1196）；显式“重新扫描”后在文件存在时恢复两首（E-1198）。删除文件并移除扫描根后保存，本地列表仍暂显示 2 首，重扫才归零（E-1200）；扫描根保存与索引重建是两个时机。

验收至少分别断言：取消后集合不变；确认框数量等于当前选择数；确认后可见集合归零；设备原文件仍存在；重启后移除状态保持；重扫按文件是否仍存在决定恢复或归零。不能只凭 toast 或列表数量变化推断文件被删除，也不能以扫描根保存成功推断索引立即更新。
