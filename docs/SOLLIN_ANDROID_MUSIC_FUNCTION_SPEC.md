# Sollin Android 音乐功能规格摘要

> 动态参考：Sollin Android 2.0.0，Android 13，1080×2340。完整截图、控件树、操作日志和哈希 Evidence 存放在外部案例目录，不进入仓库。

## 范围

本规格覆盖发现、平台音乐入口、推荐、榜单、歌单、搜索、听歌识曲、播放器、歌词、播放队列、音乐库、本地音乐、下载相关动作、EQ、音质与换源、主题和数据管理。Sollin 自有登录、用户中心、服务与反馈不在范围内；音乐平台账号只作为推荐、歌单和搜索的数据来源。

## 功能骨架

- 全局壳层：发现、音乐库、本地、设置四个主入口；搜索独立入口；底部常驻 mini 播放器。
- 发现：精选/榜单/歌单三段切换；每日推荐、推荐歌单、心动模式、收藏歌单、创建歌单快捷入口；数字专辑、新碟首发、风格化推荐。
- 推荐：歌单按全部/热门/情感/场景/语种/主题分类；风格化推荐先选曲风/语种/情感/主题/场景，再最多选择 5 个标签生成。
- 搜索：歌曲/歌单/专辑/艺术家/MV；全部、网易云、QQ、酷我、酷狗、咪咕平台筛选；结果保留平台和质量徽章，歌单结果提供打开。
- 播放器：封面驱动背景、歌词、音质徽章、环形播放键、上一首/下一首、循环、收藏、队列、歌词、更多。
- 队列：当前序号/总数、定位、清除当前之后、清空、随机、锁定；逐行上移、下移、删除。
- 歌曲菜单：播放/下一首/收藏/歌单/下载；倍速 0.5–3.0x；歌词偏移 ±0.1/±0.5s；睡眠定时（15/30/45/60/90分钟、自定义小时/分钟、播完当前歌曲再停止，提交后可取消）；输出设备；解析链路；分享；相似歌曲。
- 歌单详情：封面、作者、平台、已加载/总首数、简介展开、收藏、刷新、播放/随机、逐首操作。
- 音乐库：新建歌单（名称、描述、封面 URL）、外部歌单导入（网易云/QQ/酷我/酷狗/咪咕）、收藏和创建歌单。
- 本地：所有歌曲/文件夹/艺术家/专辑/歌单；添加文件夹、含子目录扫描、重新扫描、屏蔽目录、最小时长、名称/时长/文件时间/艺术家/专辑排序。
- 听歌识曲：麦克风和内置音频两种来源；约 3 秒识别。麦克风需要运行时权限；内置音频需要 Android 10+ 和整屏音频授权，受保护内容可能失败。

## 2026-10-24 动态状态补充

- LX 可用性检查允许选择音质与平台；固定测试曲目返回链接不代表具体歌曲实际可下载。歌曲下载质量可能全部“未检测到”，任务随后以请求/实际档位和错误原因失败，并可在下载管理器删除失败记录。
- 本地扫描需要目录授权与“音乐和音频”权限。使用隔离 WAV 验证了 `0 首 → 1 首 → 实际播放 → 删除后 0 首`；进一步用根目录/子目录两首 WAV 验证了文件夹、艺术家、专辑聚合和清理闭环；无歌词时显示空态。
- 熄屏后唤醒并上滑可回到 Sollin；播放时 Android 媒体通知显示歌曲、上一首/播放/下一首/循环与进度控制。
- 听歌识曲：麦克风在授权并播放足够音量的同一在线曲目后成功匹配；内置音频在整屏投射授权后返回两个匹配结果；未匹配和权限等待态也已记录。
- 下载：网易云歌曲320K真实下载达到100%、6.21MB并出现完成MP3；应用内删除确认会连同歌词、封面和meta数据清理，完成列表恢复为空。
- 系统输出：播放设备中的系统媒体输出选择器仍返回Android dialog不可用错误；本机播放路径保持可用。
- 生命周期：Home 返回保留页面/媒体会话；强制停止后重启回到发现首页且当前媒体会话无活动，二者必须分开实现。
- 本地多文件：无标签文件按默认值聚合；带 ID3 标签时歌曲标题/艺术家/专辑均被读取，艺术家视图按相同艺术家合并为 2 首，专辑视图拆分为 Album One/Two 各 1 首，文件夹视图保留物理路径；同标题、多艺术家、缺失艺术家和共享专辑同时存在时仍保留三行、按艺术家拆分并按专辑合并（E-972）；删除精确文件并移除扫描范围后恢复空态。
- 歌单与定时器：发现快捷入口可打开“创建的歌单”双列页；全屏播放器睡眠定时器支持自定义滚轮，实际提交32分钟后显示倒计时并可取消恢复关闭态。
- 本地排序：排序面板提供名称、时长、文件修改时间、添加时间、艺术家、专辑及正序/倒序；时长、艺术家、专辑排序保留未知标签项；不同修改时间和分批加入样本已验证文件修改时间、添加时间正序；同一时长以及同一文件修改时间的方向切换都会反转名称次级顺序，混合缺失艺术家/标题仍参与排序，清理后回空态。
- 歌单动作：歌曲更多可打开“添加到歌单”并进入三字段新建表单；音乐库新建歌单可保存名称/描述，force-stop 重启后仍保留，删除确认后回到0歌单空态（E-852/E-854/E-856）。这证明设备内持久化与删除闭环；歌曲可加入并从歌单内移除（E-858/E-860），本地备份导出/导入恢复（E-870/E-872）以及同设备云端备份上传、预览、恢复（E-876/E-878/E-880）已验证，同设备统计上传/下载合并与歌单/收藏立即同步已验证；实时同步开启时会回灌云端歌单，本地删除传播和跨设备同步仍未验证。
- 队列锁定：当前队列页锁定后会隐藏逐行编辑控件；从每日推荐内的搜索入口选中歌曲后，当前播放切换为搜索结果、队列重建为10/32并恢复开放编辑（E-918/E-920/E-922）；从推荐歌单选另一首会重建为2/30并恢复开放编辑（E-964/E-966），从相似歌曲选曲会重建为1/5并恢复开放编辑（E-968）。实现需明确锁定作用域，其他未采集入口仍需复核，不能宣称已阻止外部替换。
- 队列操作：返回播放界面、清除当前之后、清空确认/停止、随机开关、逐行删除和上移均已自动验证，并记录总数/当前索引的变化；随机播放开启态在本轮 force-stop/relaunch 和真实设备重启后仍保持（E-942/E-944/E-946），跨账号持久化未验证。
- 下载管理器边界：完成态会禁用全部暂停/继续并保留已完成文件，删除下载目录并刷新后回到空态；请求完成过快，未捕获暂停/恢复；32 KB/s 全局代理复测没有 CONNECT 且请求立即完成（E-960）；提交后约50ms force-stop 的复测未留下可恢复任务（E-924/E-926），完整进程重启续传和后台调度仍未验证。
- 睡眠定时器短曲边界：本地约4秒单曲在“列表循环”“单曲循环”“随机播放”下开启“播完当前歌曲再停止”后等待10秒，媒体会话均仍为播放态并回到同一首起点；该结果只约束本地短曲和单曲队列，在线曲目“嗜好”曲尾后继续播放并进入下一首（E-986）；多歌曲随机队列“雀跃”曲尾后切换“灰姑娘”（E-988）；在线单曲循环“要”曲尾后回到同一首继续播放（E-1006/E-1008）；其他模式仍未验证（E-962/E-970/E-974）。
- 本地索引与搜索：本地搜索显示 `N/总数` 并可清除；歌曲更多提供“从本地列表移除（保留设备原文件）”，重扫可恢复索引项；移除正在播放的文件不会立即清除 mini/media-session。扫描设置可以保存时长阈值和屏蔽路径，但在清空索引后重新授权同一根目录并推送1/2/3/10秒样本，仍显示全部4首，当前版本未观察到实际过滤生效（E-844/E-846/E-848）。
- 歌单删除：自建测试歌单删除先显示“已删除 + 撤销”提示，随后“我的歌单”回到0，保留每日推荐/收藏入口（E-796/E-798）；新建、重启持久化和删除闭环见 E-852/E-854/E-856。
- 数据与存储：缓存管理显示缓存与播放缓存容量，清理确认明确下载音频不受影响；听歌统计提供歌曲/专辑/歌手/时长/播放次数和日期时段图；播放历史支持逐行删除与清空；备份包含收藏、自建歌单、播放/歌词设置、EQ预设、歌词偏移和统计，但排除账号与已下载音乐；多设备同步把歌单/收藏实时同步与统计手动上传/下载分开；同设备统计上传、下载合并和歌单/收藏立即同步已验证；实时同步开启时本地删除的云端歌单会在重启回灌，关闭实时同步后保持空态；空 WebDAV 地址会拒绝测试（E-800–E-814、E-898–E-914）。
- 外观：主题背景页提供主题模板、纯色/渐变/图片背景、颜色和导入/导出/恢复默认；软件主题支持白天/晚上/跟随系统，图标有6种颜色，全局字体支持系统/衬线/等宽/导入，播放器样式和底部栏材质有独立枚举（E-816–E-828）。本轮只记录选项，不把赞助或动态效果写成功能完成。
- 下载设置：附加 lrc/jpg/meta、平台质量、保存位置、命名顺序与分隔符、按平台封面尺寸、1–3并发和任务管理均为独立配置；2/3并发有失败风险提示，默认目录为 `/storage/emulated/0/Music/SollinV2`（E-830–E-838）。真实下载暂停/恢复、后台续接和进程重启续传仍未验证；12 KB/s 与 32 KB/s 限速代理复测都在暂停控件可用前完成；后一次请求未经过该全局代理（E-874、E-916、E-960）。
- 下载断网边界：提交后立即关闭 Wi‑Fi/移动数据会得到0%失败、网络不可达原因及重试/移除记录；恢复网络后失败记录仍保留并与已完成任务并列（E-840/E-842）。暂停中间态和断点续传仍未验证。
- 最终清理：批量移除下载任务记录，删除音频与 lrc/jpg/meta 侧车，删除 NexusFilter 并重扫；设备最终本地页为0首歌曲，下载目录和测试目录为空，媒体会话暂停（E-850）。
- 本轮确认设备约束：屏幕熄灭超时 600000ms（10 分钟）、`stay_on_while_plugged_in=0`、Sollin `MANAGE_EXTERNAL_STORAGE=allow`；最终播放已暂停，隔离文件已从手机删除。

## 设计与状态约束

1. 统一维护 `provider`、`source`、`track`、`playback`、`queue`、`playlist`、`localScan`、`discovery` 状态。发现、搜索、歌单、mini、全屏播放器和队列必须共享当前播放意图。
2. 歌曲行是跨页面复用单元：封面、歌名、质量、艺人/平台、更多动作。更多菜单根据当前歌曲状态显示播放、下载等动作。
3. 播放解析链路应显示来源平台、音源选择、缓存命中、真实链接、加载、缓冲和音频就绪；不能只显示最终播放成功。
4. 空态、权限拒绝、系统输出不可用、受保护音频和平台无结果都要有可解释的状态与返回路径。
5. 默认主题是浅色粉/珊瑚红，播放器和队列随封面变更深色/棕色。圆角半透明卡片、底部胶囊和大标题是共同视觉令牌；逐页像素验收仍以同状态截图为准。
