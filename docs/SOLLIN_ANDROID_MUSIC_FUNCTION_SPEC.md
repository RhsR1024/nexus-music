# Sollin Android 音乐功能规格摘要

> 动态参考：Sollin Android 2.0.0，Android 13，1080×2340。完整截图、控件树、操作日志和哈希 Evidence 存放在外部案例目录，不进入仓库。

## 范围

本规格覆盖发现、平台音乐入口、推荐、榜单、歌单、搜索、听歌识曲、播放器、歌词、播放队列、音乐库、本地音乐、下载相关动作、EQ、音质与换源、主题和数据管理。Sollin 自有登录、用户中心、服务与反馈不在范围内；音乐平台账号只作为推荐、歌单和搜索的数据来源。

## 功能骨架

- 全局壳层：发现、音乐库、本地、设置四个主入口；搜索独立入口；底部常驻 mini 播放器。
- 发现：精选/榜单/歌单三段切换；每日推荐、推荐歌单、心动模式、收藏歌单、创建歌单快捷入口；数字专辑、新碟首发、风格化推荐。
- 推荐：歌单按全部/热门/情感/场景/语种/主题分类；风格化推荐先选曲风/语种/情感/主题/场景，再最多选择 5 个标签生成。
- 搜索：歌曲/歌单/专辑/艺术家/MV；全部、网易云、QQ、酷我、酷狗、咪咕平台筛选；结果保留平台和质量徽章，歌单结果提供打开。
- 播放器：封面驱动背景、歌词、音质徽章、环形播放键、上一首/下一首、循环、收藏、队列、歌词、更多。
- 队列：当前序号/总数、定位、清除当前之后、清空、随机、锁定；逐行上移、下移、删除。
- 歌曲菜单：播放/下一首/收藏/歌单/下载；倍速 0.5–3.0x；歌词偏移 ±0.1/±0.5s；睡眠定时；输出设备；解析链路；分享；相似歌曲。
- 歌单详情：封面、作者、平台、已加载/总首数、简介展开、收藏、刷新、播放/随机、逐首操作。
- 音乐库：新建歌单（名称、描述、封面 URL）、外部歌单导入（网易云/QQ/酷我/酷狗/咪咕）、收藏和创建歌单。
- 本地：所有歌曲/文件夹/艺术家/专辑/歌单；添加文件夹、含子目录扫描、重新扫描、屏蔽目录、最小时长、名称/时长/文件时间/艺术家/专辑排序。
- 听歌识曲：麦克风和内置音频两种来源；约 3 秒识别。麦克风需要运行时权限；内置音频需要 Android 10+ 和整屏音频授权，受保护内容可能失败。

## 2026-10-24 动态状态补充

- LX 可用性检查允许选择音质与平台；固定测试曲目返回链接不代表具体歌曲实际可下载。歌曲下载质量可能全部“未检测到”，任务随后以请求/实际档位和错误原因失败，并可在下载管理器删除失败记录。
- 本地扫描需要目录授权与“音乐和音频”权限。使用隔离 WAV 验证了 `0 首 → 1 首 → 实际播放 → 删除后 0 首`，扫描设置可保留或移除精确目录；无歌词时显示空态。
- 熄屏后唤醒并上滑可回到 Sollin；播放时 Android 媒体通知显示歌曲、上一首/播放/下一首/循环与进度控制。
- 听歌识曲：麦克风在授权并播放足够音量的同一在线曲目后成功匹配；内置音频在整屏投射授权后返回两个匹配结果；未匹配和权限等待态也已记录。
- 下载：网易云歌曲320K真实下载达到100%、6.21MB并出现完成MP3；应用内删除确认会连同歌词、封面和meta数据清理，完成列表恢复为空。
- 系统输出：播放设备中的系统媒体输出选择器仍返回Android dialog不可用错误；本机播放路径保持可用。
- 生命周期：Home 返回保留页面/媒体会话；强制停止后重启回到发现首页且当前媒体会话无活动，二者必须分开实现。
- 本轮确认设备约束：屏幕熄灭超时 600000ms（10 分钟）、`stay_on_while_plugged_in=0`、Sollin `MANAGE_EXTERNAL_STORAGE=allow`；最终播放已暂停，隔离文件已从手机删除。

## 设计与状态约束

1. 统一维护 `provider`、`source`、`track`、`playback`、`queue`、`playlist`、`localScan`、`discovery` 状态。发现、搜索、歌单、mini、全屏播放器和队列必须共享当前播放意图。
2. 歌曲行是跨页面复用单元：封面、歌名、质量、艺人/平台、更多动作。更多菜单根据当前歌曲状态显示播放、下载等动作。
3. 播放解析链路应显示来源平台、音源选择、缓存命中、真实链接、加载、缓冲和音频就绪；不能只显示最终播放成功。
4. 空态、权限拒绝、系统输出不可用、受保护音频和平台无结果都要有可解释的状态与返回路径。
5. 默认主题是浅色粉/珊瑚红，播放器和队列随封面变更深色/棕色。圆角半透明卡片、底部胶囊和大标题是共同视觉令牌；逐页像素验收仍以同状态截图为准。
6. 连续手势、歌词滚动、队列拖动、抽屉弹簧和播放器转场必须用真机录屏验收；静态截图只能证明容器、层级和静态常量。

## 首批实现顺序

1. 主壳层、安全区、mini 播放器、歌曲行和通用歌曲菜单。
2. 发现精选、榜单、推荐歌单、每日推荐、搜索结果、歌单详情，先打通统一播放队列。
3. 全屏播放器、歌词、队列、解析链路、相似歌曲、倍速/睡眠/偏移。
4. 音乐库、本地扫描、导入、下载任务、缓存/统计/备份。
5. 主题、播放器样式和动效逐页收敛。
