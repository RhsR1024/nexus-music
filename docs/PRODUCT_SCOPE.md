# 产品功能清单与验收范围

日期：2026-10-14。状态：需求基线，已授权开始实施；实现进度见 TASK_PLAN.md，以下功能仍按各项验收。用户已确认项与建议项分开记录。

## 定位与首版边界

音枢 NexusMusic：iOS 优先的在线音乐与 Navidrome 曲库统一播放器，后续可能支持 Android。

现有功能目标来自漫途/LX，但首版已经收窄为在线来源 + Navidrome。没有任何参考项目被视为可直接换名的成品。UI 重新按 iPhone 设计。

## 首版核心目标

| 编号 | 功能 | 验收结果应当是什么 | 状态 |
| --- | --- | --- | --- |
| F01 | 在线平台元数据 | 网易云/QQ/酷我/酷狗/咪咕按 provider 提供搜索、歌单分类和榜单；逐平台记录可用与降级，不因一个平台成功宣称全通过 | 目标保留，接口待联调 |
| F02 | 聚合搜索 | 按平台或聚合查看结果；分页、取消、去重和旧请求保护；不把同名不同版本直接合并 | 目标保留 |
| F03 | 发现、分类、排行榜 | 展示返回的歌单封面、名称、分类、榜单和歌曲；缺失可选字段不造假 | 目标保留 |
| F04 | LX 音源管理 | 本地 JS/URL 导入、列表、批量选择/启用/停用/删除、多个音源同时生效、自动择源、版本说明与更新；保留订阅/升级目标 | 核心，2026-10-15明确 |
| F05 | 脚本兼容 | 初始化、musicUrl、可选 lyric/pic、HTTP/取消/二进制、加密/编码/zlib 等实际依赖可用；受控生命周期 | 必须验证 |
| F06 | 播放与系统控制 | 播放/暂停/定位/上一首/下一首、锁屏/控制中心、耳机/蓝牙、来电与音频路由中断；锁屏后能解析下一首新 URL | 核心 |
| F07 | 队列 | 单曲插入、下一首 FIFO、拖动、删除、清空、当前高亮、顺序/循环/随机、失败处理 | 目标保留 |
| F08 | 音质 | 用户音质偏好优先；同档跨源尝试完再逐级降档；UI区分偏好、成功请求档位、实际媒体信息与失败；不保证每源八档可用 | 核心，2026-10-15明确 |
| F09 | 歌词 | 普通行级、偏移、滚动、点行定位；有逐字/翻译/罗马音时按真实数据支持；无词明确显示无词 | 目标保留，逐字解析需按格式验收 |
| F10 | 歌词样式/字体 | 字号、色彩等基础样式；保留字体文件导入/管理目标；不依赖车机扫码网页 | 目标保留，样式细项待形成 UI 稿 |
| F11 | 本地收藏/历史/歌单 | 持久化、创建/删除/编辑、增删歌曲、曲序、重复项规则、批量操作；它们不是“本地音乐文件管理” | 核心 |
| F12 | 漫途歌单一次导入 | 用户导出文件→格式识别→预览→导入结果；保留来源 ID、顺序和重复曲目；失败不破坏已有数据 | 用户明确要求，最新指令移到最后 |
| F13 | 公开平台歌单导入 | 保留普通平台分享链接/JSON导入目标，按平台能力适配；来源刷新不覆盖失败旧数据；不包含汽水 | 目标保留 |
| F14 | Navidrome 连接 | 地址/账号配置、连接验证、错误区分；客户端鉴权材料安全保存；支持用户实际部署路径 | 用户明确首期 |
| F15 | Navidrome 浏览/搜索/播放 | 歌曲、专辑、歌手、歌单、封面、搜索和 stream；分页、取消和权限降级 | 首期核心 |
| F16 | Navidrome 音频信息/歌词 | 返回则显示格式、码率等；歌词与扩展按服务器能力探测；原文件属性不冒充转码后实际属性 | 条件能力 |
| F17 | 临时缓存 | URL、封面、歌词、必要音频缓存边界明确；可清理、有限容量、失效恢复；与永久离线保存分开 | 目标保留 |
| F18 | 外观与交互 | 明暗主题、迷你播放器、完整播放页、纵屏、手势与无障碍基础；界面字段来自 DATA_CAPABILITIES | 已授权重新设计 |
| F19 | 数据与错误恢复 | 数据版本、原子写入、导出备份能力、可用诊断；不引入必需自建服务器 | 建议工程基线 |
| F20 | IPA 与自签使用 | 可重复构建 unsigned IPA，安装/续签后重要数据保留；无永久有效承诺 | 使用目标 |
| F21 | 真实频谱与EQ | 原生PCM计算频谱；均衡器开关、频段增益、预设及持久化；验证旁路、削波余量和中断恢复 | 2026-10-15明确纳入首版，待实现 |
| F22 | 离线保存与下载管理 | 保存离线、下载列表、暂停/继续、失败重试、容量统计与清理；临时缓存独立管理 | 保留在最后M10，待实现 |

F01–F22 是待实施清单，不是交付记录。阶段性版本可以分批实现，但不得因延期改变用户已要求的总范围；变更需明确记录。

## 明确排除/延期

| 项目 | 当前处理 |
| --- | --- |
| 汽水 | 首期不做：账号/推荐/场景/原生播放及其专用导入不进入首期 |
| ECARX | 不实现 OEM SDK、车机来源注册、语音/收藏桥与恢复策略 |
| CarPlay | 不实现模板、entitlement 和车载界面；普通蓝牙不受此排除影响 |
| 车机扫码上传 | 不做字体/音源上传网页、本地接收服务器与配对链 |
| 本地音乐文件管理 | 先不做扫描、目录库、文件标签编辑和 USB 曲库；JS/字体/歌单文件导入不是此项 |
| Emby / SMB | 不进入首期，架构可以留 provider 边界，不编写未使用平台实现 |
| Android 版本 | 保留未来可能，首期不交付 Android，不承诺零成本移植 |
| 漫途持续同步 | 不做跨端持续双向同步；只做一次歌单导入 |
| 夸克自动云同步 | 不作为本轮确定的首期能力；一次迁移不需要它。如用户另行要求云备份，重新明确范围 |
| 原样跨应用悬浮歌词 | iOS 无等价 Android 公共悬浮窗方案；不承诺还原；画中画另议 |
| 评论、小组件、Live Activities | 没有明确首期要求，默认不为了参考项目有而新增 |
| App Store/TestFlight 发布 | 不是本轮目标；免费自签不能当作正式发布渠道 |

## 验收用语

- “代码实现”与“真实平台成功”分开；实时接口可能改变。
- “无损”只在文件/输出证据充分时使用；档位按钮不是证据。
- 一个平台返回封面/文件大小，不代表所有平台都有。
- 一个音源返回 URL，不代表它提供搜索/歌词/封面。
- 导入歌单不会导入会员、登录状态或音乐版权权限；缺少音源时能保留歌单但需提示未配置播放来源。
